Bibliothèque et sources

Toutes les références de la première version sont conservées. Les tutoriels sont rédigés et intégrés dans les chapitres ; cette page permet de retrouver les documents d’origine, les téléchargements et les ressources complémentaires.

Les pages du Campus RÉCIT concernant le monde simple, les mouvements et Code Builder ont présenté une protection anti-robot lors de cette refonte. Les tutoriels correspondants sont donc des adaptations fondées sur la documentation officielle et le contenu initial, pas des transcriptions de ces pages. Les vidéos externes nécessitent Internet et une autorisation de lecture intégrée.

À propos des contenus

Les schémas, activités, adaptations et simulateurs de ce site sont des créations pédagogiques originales. Les vidéos sont proposées via leur lecteur externe, sans copie. Le site n’inclut ni l’application Minecraft, ni les mondes officiels, ni le contenu intégral des sites tiers. Les instructions et exemples de code doivent être testés dans la version utilisée en établissement.
