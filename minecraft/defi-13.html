13Piloter l’Agent : mission de livraison

Programmation & projet · 5e–4e · 45 min
Situation-problème
Un robot doit rejoindre une zone de livraison sans heurter les murs.
Cahier des charges
Trajet imposé avec deux virages ; programme lancé par chat ; arriver au repère sans intervention manuelle.
Étapes proposées
Dessiner le chemin ; compter les déplacements ; orienter l’Agent ; écrire la séquence de mouvements et rotations ; exécuter ; corriger.
Production à remettre
Algorithme, capture du code, photo de l’arrivée.

Atelier guidé · Défi 13

Retrouve la mission et les contraintes au-dessus. Avant de commencer, prépare ton espace de travail.

Situation-problème

Un robot doit rejoindre une zone de livraison sans heurter les murs.

Cahier des charges

Trajet imposé avec deux virages ; programme lancé par chat ; arriver au repère sans intervention manuelle.

Production à remettre

Algorithme, capture du code, photo de l’arrivée.

Matériel à préparer

  • Blocs de sol colorés
  • Agent
  • Code Builder (C)
  • MakeCode

Étape par étape

  1. Créer le parcours en U avec départ bleu et arrivée verte.
  2. Se tenir au départ, orienter l’Agent vers +X (est) et le placer sur le repère.
  3. Ouvrir Code Builder (C), choisir MakeCode et créer un projet.
  4. Dans Joueur, ajouter un événement sur commande chat livraison ; dans Agent, déplacer et tourner.
  5. Assembler : avancer 4, droite, avancer 3, droite, avancer 4.
  6. Lancer avec livraison dans le chat (sans /), tester, puis remettre l’Agent au départ avant chaque essai.

Plan de départ

Vérifications avant de rendre

Trois indices, à ouvrir seulement si nécessaire

Indice 1

Commencer par un seul mouvement.

Indice 2

Un virage ne fait pas avancer.

Indice 3

L’Agent revient en X au même niveau mais Z a augmenté de 3.

Résultat de référence

Le fichier MakeCode est un source JavaScript à coller, pas un monde ni un projet importable.

Validation

Solution possible, critères et prolongement Correction / validation : Exemple pour un parcours en L puis retour parallèle : avancer 4, tourner droite, avancer 3, tourner droite, avancer 4 (selon l’orientation initiale). Tester chaque segment. Pour aller plus loin : Factoriser un motif de déplacement avec une boucle.

Code MakeCode — JavaScript

Dans Code Builder, créer un projet, passer en JavaScript, coller le code puis lancer le projet. Replacer et orienter l’Agent avant chaque essai. Enregistrer le projet depuis MakeCode.

player.onChat("livraison", function () {
    agent.setAssist(DESTROY_OBSTACLES, false)
    agent.setAssist(PLACE_ON_MOVE, false)
    agent.move(FORWARD, 4)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 3)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 4)
})

Pack expérimental : à tester. Aucun fichier .mcworld préconstruit n’est fourni. Le fichier MakeCode est un source JavaScript à coller, pas un monde ni un projet importable.

Générer les deux mondes

Préparation (enseignant uniquement). Importer le pack de comportement dans Minecraft Education en ouvrant le fichier .mcpack. Créer un monde plat, vierge, créatif, activer le pack dans Packs de comportement et autoriser les commandes. Se placer au sol, loin de toute construction, sans voler. Les commandes modifient jusqu’à 32 × 25 blocs à partir du joueur (vers +X et +Z) et peuvent écraser les blocs présents. Utiliser une nouvelle copie pour chaque génération.

Si /function n’est pas disponible, utiliser le fichier .mcfunction comme liste de commandes à saisir une à une dans le chat, avec le préfixe / (omettre le commentaire initial). Rester au même emplacement pendant la génération. Exporter ensuite le monde depuis la liste des mondes (Modifier → Exporter le monde, selon version). Les mondes .mcworld doivent être obtenus dans le jeu : ils ne sont pas inclus dans ce pack.

  1. Dans un monde élève vierge : /function techno/d13_eleve.
  2. Dans un autre monde vierge : /function techno/d13_correction.
  3. Terminer les manipulations indiquées dans Correction, effectuer les tests et exporter chaque monde au format .mcworld.
