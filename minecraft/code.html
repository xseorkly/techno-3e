MODULE 07

Programmer avec Code Builder et MakeCode

Faire programmer un robot virtuel : de la séquence élémentaire à l’algorithme paramétrable.

Premier programme en 5 étapes

  1. Dans un monde créatif, appuyer sur C pour ouvrir Code Builder. Sur tablette, utiliser l’icône correspondante.
  2. Choisir MakeCode et créer un nouveau projet. Repérer les catégories Joueur, Agent, Boucles, Logique, Variables.
  3. Glisser l’événement « lors de la commande de chat » ; lui donner le nom avance.
  4. Ajouter les blocs pour téléporter l’Agent jusqu’au joueur, puis le faire avancer de 5 blocs.
  5. Lancer le programme depuis l’éditeur si nécessaire, revenir dans le monde, ouvrir le chat avec T, saisir avance sans barre oblique et valider.
Lors de la commande « avance »
Téléporter l’Agent au joueur
Agent : avancer de 5 blocs

Blocs schématisés, pas une capture de l’éditeur. Les libellés exacts peuvent varier.

player.onChat("avance", function () {
    agent.teleportToPlayer()
    agent.move(FORWARD, 5)
})

Exemple JavaScript MakeCode, à saisir dans l’éditeur JavaScript de Minecraft (et non dans la console du navigateur). Vérifier que l’Agent dispose d’un trajet dégagé.

Deuxième programme : poser une rangée de cinq blocs

Le robot doit recevoir le matériau et sélectionner son emplacement. Sur sol plat, placez l’Agent sur le sol à côté de la zone de construction et laissez son trajet libre. À chaque déplacement il pose un bloc derrière lui grâce à l’assistance de placement. Tester le décalage du premier bloc avant de lancer une construction longue.

Lors de la commande « ligne »
Téléporter l’Agent au joueur
Mettre 64 blocs de pierre dans le slot 1
Sélectionner le slot 1
Activer placement en mouvement
Répéter 5 fois
Avancer de 1 bloc
Désactiver placement en mouvement
player.onChat("ligne", function () {
    agent.teleportToPlayer()
    agent.setItem(STONE, 64, 1)
    agent.setSlot(1)
    agent.setAssist(PLACE_ON_MOVE, true)
    for (let i = 0; i < 5; i++) {
        agent.move(FORWARD, 1)
    }
    agent.setAssist(PLACE_ON_MOVE, false)
})

Troisième programme : réagir à un obstacle

Si l’Agent détecte un bloc devant lui, il tourne à droite ; sinon il avance. Limiter à 20 itérations évite une boucle infinie. Ce comportement réactif ne garantit pas de sortir de tous les labyrinthes.

Commande « explore »
Répéter 20 fois
SI Agent détecte un bloc devant
Tourner à droite
SINON
Avancer de 1
player.onChat("explore", function () {
    for (let i = 0; i < 20; i++) {
        if (agent.detect(AgentDetection.Block, FORWARD)) {
            agent.turn(TurnDirection.Right)
        } else {
            agent.move(FORWARD, 1)
        }
    }
})

TUTORIEL 01

Agent Moves : piloter un robot pas à pas

  1. Ouvrir Code Builder avec C dans un monde autorisant la programmation ; créer un projet MakeCode.
  2. Créer quatre événements du chat : tp (téléporter l’Agent), fd (avancer), rt (tourner à droite), lt (tourner à gauche). Ajouter un seul bloc Agent dans chaque événement.
  3. Revenir dans le jeu et saisir tp, puis fd, rt, fd. Observer l’orientation du robot et dessiner son trajet.
  4. Transformer ces commandes en un seul événement parcours avec la séquence avancer de 3, tourner à droite, avancer de 2. Tester sur un sol dégagé.
Résultat à vérifier
Le trajet réel correspond au trajet dessiné avant exécution.

TUTORIEL 02

Agent Build : construire automatiquement

  1. Préparer une zone dégagée. Charger un matériau dans le premier emplacement de l’Agent, puis le sélectionner.
  2. Créer une commande de chat ligne. Activer le placement en déplacement, faire avancer le robot de cinq blocs, puis désactiver le placement.
  3. Tester, observer la position du premier et du dernier bloc. Adapter le nombre de pas et l’orientation pour réaliser un carré.
  4. Remplacer les répétitions manuelles par une boucle. Contrôler la consommation de blocs et comparer le code avec un plan coté.
Résultat à vérifier
Une ligne ou un carré reproductible, avec code et photo.

TUTORIEL 03

Agent Wall : réaliser un mur paramétrable

  1. Choisir une longueur L=5 et une hauteur H=3. Dessiner les rangées sur papier. Charger suffisamment de blocs.
  2. Créer la première rangée en reprenant le programme ligne. Faire monter l’Agent d’un bloc et retourner son orientation pour parcourir la rangée suivante.
  3. Utiliser une boucle sur les rangées ; désactiver le placement pendant les déplacements verticaux et les repositionnements. Tester d’abord un mur de 2 × 2.
  4. Remplacer les valeurs fixes par des paramètres ou variables. Vérifier les dimensions finales et noter le décalage éventuel lié au point de départ.
Résultat à vérifier
Un mur de dimensions demandées et un programme adaptable.

TUTORIEL 04

GameCode : inventer un mini-jeu technique

  1. Définir une règle simple : rejoindre une zone en respectant un parcours ou déclencher une action lorsque le joueur atteint un objectif.
  2. Utiliser un événement pour lancer la partie et une variable de score ; prévoir une condition de réussite.
  3. Programmer un retour visuel ou un message, tester le cas réussi et le cas échoué. Faire tester par un autre groupe.
  4. Écrire les règles du mini-jeu et expliquer les événements, conditions et variables employés. Il s’agit d’une adaptation en technologie, non de la reproduction des leçons officielles.
Résultat à vérifier
Un mini-jeu testable avec une règle et un critère de victoire.
