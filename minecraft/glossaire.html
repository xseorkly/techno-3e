LES MOTS DE MINECRAFT

Glossaire

Les mots que tu vas rencontrer dans le jeu et dans les défis, expliqués simplement.

Bloc
Le cube de base de Minecraft (1 bloc = 1 m si on le décide). Chaque matériau est un bloc : pierre, bois, verre, béton…
Monde
Le terrain dans lequel on construit. Il est enregistré dans un fichier .mcworld qu’on peut partager.
Fichier .mcworld
Un monde « emballé » dans un fichier. Double-cliquer dessus l’importe dans Minecraft Education.
Mode Créatif
Mode de jeu où l’on a tous les blocs à volonté et où l’on peut voler. C’est le mode des défis de technologie.
Mode Survie
Mode où il faut récolter les ressources, manger et éviter les dangers. Peu utilisé en technologie.
Inventaire
La liste de tous les blocs et objets disponibles. S’ouvre avec E.
Barre rapide
Les 9 cases en bas de l’écran : les objets que l’on a en main. On choisit avec les chiffres 1 à 9 ou la molette.
Réticule
La petite croix au centre de l’écran. C’est l’endroit que l’on vise pour poser ou casser.
Coordonnées (X, Y, Z)
L’adresse d’un point du monde. X et Z : position au sol. Y : hauteur.
Point d’apparition
L’endroit où l’on arrive en entrant dans le monde.
Redstone (poudre de redstone)
Une poudre rouge qui transporte un signal, comme un fil électrique. Sert à fabriquer des automatismes.
Levier
Un interrupteur : il envoie un signal tant qu’il est en position « marche ».
Plaque de pression
Un capteur de présence : il envoie un signal quand un joueur marche dessus.
Lampe de redstone
Une lampe qui s’allume quand elle reçoit un signal. C’est un actionneur.
Torche de redstone
Inverse le signal (fonction NON) : allumée sans signal, éteinte avec signal.
Répéteur
Prolonge un signal trop faible et peut le retarder.
Agent
Un petit robot que l’on programme avec MakeCode pour qu’il construise ou se déplace à notre place.
Constructeur de code (Code Builder)
La fenêtre de programmation dans le jeu. S’ouvre avec la touche C.
MakeCode
L’outil de programmation par blocs (comme Scratch) utilisé pour programmer l’Agent.
Commande
Une instruction tapée dans le chat (touche T) qui commence par /, par exemple /time set day. Réservée en général au professeur.
Héberger / Rejoindre
Le professeur héberge (ouvre) un monde ; les élèves le rejoignent avec un code en images pour travailler à plusieurs.
Appareil photo et Portfolio
Des objets de l’inventaire pour photographier sa construction et garder ses photos avec un commentaire.
PNJ
Personnage non joueur : un personnage placé par le professeur qui donne des consignes dans le monde.
