Espace enseignant

Tout pour lancer Minecraft Education en technologie, même si vous n’avez jamais joué : une check-list, une première séance clé en main, les mondes prêts à distribuer et un guide de dépannage.

Conseil : faites vous-même les Premiers pas avant la première séance (45 minutes). C’est le meilleur moyen d’anticiper les difficultés des élèves.

Les cases cochées restent enregistrées sur ce navigateur.

2 · Première séance clé en main (55 min)

Objectif : chaque élève sait se déplacer, poser des blocs et lire ses coordonnées. Support élève : Premiers pas. Monde : monde d’entraînement « Premiers pas ».

3 · Mondes des défis

Chaque défi a deux mondes : le monde élève (terrain de départ à distribuer) et le monde corrigé (résultat attendu, pour vous ou pour une correction projetée). Tous sont en mode Créatif, terrain plat, coordonnées affichées.

Mondes corrigés : seul celui du défi 16 est disponible pour l’instant ; en attendant, les captures « résultat attendu » de chaque défi et les fiches corrigées montrent la solution.

Distribuer un monde : déposez le fichier .mcworld sur Teams ou l’ENT. Chaque élève le télécharge et double-clique dessus. Le fichier d’origine n’est jamais modifié : en cas d’erreur, il suffit de le réimporter.

Méthode avancée : recréer ou modifier les mondes avec le pack

Les mondes ont été générés avec le pack de comportement Technologie_16_defis.mcpack et la commande /function techno/dXX_eleve (ou dXX_correction) dans un monde plat, vierge, créatif, avec les commandes autorisées. Cette méthode n’est utile que pour adapter un monde. Notice : installation du pack.

4 · Dépannage

« Vous n’avez pas de licence » / connexion refusée

Le compte n’a pas de licence attribuée ou n’appartient pas au bon tenant. À régler par le service informatique ; ne jamais utiliser un compte personnel.

Le double-clic sur le .mcworld n’ouvre pas le jeu

Ouvrir Minecraft → Jouer → Importer, et choisir le fichier dans Téléchargements.

Les élèves ne peuvent pas voler

Le monde est en mode Survie. Ouvrir le monde → Paramètres → Mode de jeu : Créatif, puis réexporter.

Les coordonnées ne s’affichent pas

Dans les paramètres du monde, activer « Afficher les coordonnées » avant d’exporter le monde distribué.

Un élève est perdu ou coincé dans le monde

Faire Échap → Sauvegarder et quitter, puis rouvrir le monde : il revient au point d’apparition.

Un élève a tout cassé

Réimporter le monde d’origine (le fichier .mcworld n’est pas modifié par le jeu).

Les élèves ne voient pas le monde partagé

Vérifier : même version du jeu, même établissement (tenant), monde hébergé ouvert sur le poste du professeur. Voir Gérer une classe.

Le jeu est très lent

Fermer les autres applications, réduire la distance d’affichage (Paramètres → Vidéo). Les postes avec moins de 8 Go de mémoire sont limites.
