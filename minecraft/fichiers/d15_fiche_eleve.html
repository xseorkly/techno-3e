Robot réactif dans un labyrinthe

Nom : _____________________   Classe : ______   Date : ______

Situation-problème

Un robot doit explorer un espace inconnu sans traverser les murs.

Cahier des charges

Détecter devant, choisir action, limiter à 20 itérations, tester sur deux parcours ; expliquer les limites.

Production à remettre

Code, deux résultats, explication d’un cas d’échec.

Matériel

Agent ; blocs de mur ; deux parcours ; MakeCode

Étapes

  1. Construire un couloir avec un virage, puis un second avec un cul-de-sac.
  2. Placer l’Agent au départ du premier parcours, face à la direction du couloir.
  3. Créer la commande chat labyrinthe ; désactiver destruction et placement automatiques.
  4. Dans une boucle de 20, tester agent.detect(BLOCK, FORWARD).
  5. Si obstacle : tourner à droite, sinon avancer d’un bloc ; exécuter sur les deux parcours.
  6. Consigner le nombre d’actions et les boucles éventuelles ; proposer une amélioration.
