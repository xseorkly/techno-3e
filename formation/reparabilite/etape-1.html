La démarche

Cinq gestes

  1. 1Constater
  2. 2Deux hypothèses
  3. 3Un test qui départage
  4. 4Cause et intervention
  5. 5Preuve
Un test qui départage : son résultat n’est pas le même selon l’hypothèse qui est vraie. Si A est vraie, le test donne un résultat ; si A est fausse, il en donne un autre.
Exemple

La lampe est morte… vraiment ?

Le soir, Lina prend la petite lampe de l’entrée. Elle appuie : rien. Les piles sont neuves. Faut-il jeter la lampe ?

1. Je constateL’interrupteur bouge. Aucune lumière.
2. Deux hypothèsesA : les piles ne fournissent pas assez d’énergie. B : le circuit est coupé quelque part.
3. Un test qui départageEssayer avec deux piles neuves dont on est sûr. Si elle reste éteinte, A est écartée. Puis regarder les contacts : si un papier isole une pile, B est confirmée.
4. Cause et interventionUn papier isolait un contact. On le retire.
5. PreuveTrois allumages de suite. Décision : nettoyer, pas remplacer.
Un coup de pouce ?

Quatre mots utiles

  • Symptôme : ce que l’on observe.
  • Cause : ce qui provoque le symptôme.
  • Hypothèse : une cause possible, à vérifier.
  • Preuve : le même essai réussi trois fois.
