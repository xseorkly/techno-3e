Point 3 · Sous-partie 3

Créer ThingSpeak et envoyer une première donnée

On crée une destination sur Internet, puis on envoie une valeur très simple. Le capteur viendra seulement après.

Étape A

Se connecter au compte enseignant

Connectez-vous à ThingSpeak avec le compte MathWorks du professeur.

Pour l’organisation de la classe, les élèves n’ont pas besoin de compte personnel : le professeur crée et administre les canaux, puis fournit seulement les paramètres utiles à chaque groupe.

Avec deux comptes professionnels, vous pourrez répartir les 7 groupes sur deux espaces ThingSpeak sans demander aux élèves de créer un compte.
Étape B

Créer un premier canal

Dans ThingSpeak, suivez exactement ce chemin :

Channels → My Channels → New Channel

Pour ce premier essai, remplissez uniquement :

ZoneValeur conseillée
NamePoste test IoT
Field 1Valeur test

Puis cliquez sur Save Channel.

Ne remplissez pas les autres champs pour l’instant. Le but est d’obtenir un premier succès avec la configuration la plus simple possible.
Étape C

Comprendre les trois informations importantes

ÉlémentQuestion à se poserRôle
Channel ID« Dans quel canal ? »Identifie le canal ThingSpeak.
Write API Key« Ai-je le droit d’écrire ? »Autorise l’objet à envoyer des données dans ce canal.
Read API Key« Ai-je le droit de lire ? »Permet la lecture d’un canal privé.
La Write API Key n’est pas le mot de passe du compte professeur. C’est une clé technique liée au canal.
Étape D

Copier la Write API Key

Dans votre canal, ouvrez l’onglet API Keys.

Repérez Write API Key, puis copiez cette clé.

Ne publiez jamais une vraie Write API Key sur une page publique ou dans un dépôt GitHub public. Sur le site de formation, nous n’utiliserons que des exemples fictifs.
Étape E

Faire le premier envoi depuis MakeCode

Revenez dans MakeCode et ajoutez le bloc d’envoi ThingSpeak de l’extension Cytron.

Write API Key = "VOTRE_CLE"
Field 1 = 22

Pour le premier test, envoyez simplement la valeur 22. C’est volontaire : si 22 arrive bien, alors le réseau et ThingSpeak fonctionnent indépendamment de tout capteur.

Étape F

Déclencher l’envoi avec le bouton A

Pour rendre le test visible, créez une variable et utilisez le bouton A :

au démarrage
    variable = 0

quand bouton A est pressé
    variable = variable + 1
    envoyer variable vers Field 1

Premier appui : 1. Deuxième appui : 2. Troisième appui : 3.

Cette méthode est très utile pour un débutant : chaque appui doit provoquer un nouveau point dans ThingSpeak.

Étape G

Vérifier le graphique

Retournez sur le canal ThingSpeak et observez le graphique de Field 1.

Si les points apparaissent, la chaîne suivante fonctionne :

micro:bit → UART → ESP8266 → Wi‑Fi → Internet → ThingSpeak
À ce stade, vous avez réussi votre première chaîne IoT, même sans capteur.
