Point 3 · Sous-partie 2

Faire communiquer la micro:bit avec le Wi‑Fi

On avance lentement : installer l’extension, dire à la micro:bit où se trouve l’ESP8266, vérifier qu’il répond, puis seulement se connecter au réseau.

Étape A

Ouvrir MakeCode

1. Ouvrez makecode.microbit.org.

2. Cliquez sur Nouveau projet.

3. Donnez-lui un nom simple : Test WiFi ThingSpeak.

4. Attendez l’ouverture de l’éditeur de blocs.

À ce stade, rien n’est encore programmé pour le Wi‑Fi. C’est normal.
Étape B

Ajouter l’extension Cytron ESP8266

1. Dans la colonne de blocs, cliquez sur Extensions.

2. Dans la zone de recherche, saisissez CytronTechnologies/pxt-esp8266.

3. Cliquez sur l’extension proposée.

4. Revenez à l’éditeur : une nouvelle famille de blocs liée à l’ESP8266 doit être visible.

Si vous ne voyez pas les blocs ESP8266, ne continuez pas. Revenez dans Extensions et vérifiez l’installation.
Étape C

Initialiser la liaison série

Dans Au démarrage, placez le bloc d’initialisation ESP8266.

TX = P16
RX = P15
Vitesse = 115200 bauds

P16 correspond à la ligne utilisée par la micro:bit pour transmettre. P15 sert à recevoir. La vitesse 115200 indique à quelle vitesse les deux cartes échangent leurs caractères.

Le programme et le branchement doivent raconter la même chose : Wi‑Fi sur P15:P16 → MakeCode configuré sur P16/P15.
Étape D

Tester l’ESP8266 avant Internet

Ajoutez un test juste après l’initialisation :

si ESP8266 initialisé
    afficher ✓
sinon
    afficher ✗

Téléchargez le programme dans la micro:bit.

Vous obtenez ✓

Très bien. La micro:bit dialogue avec le module Wi‑Fi. Vous pouvez continuer.

Vous obtenez ✗

Vérifiez, dans cet ordre : REKA:BIT sur ON, alimentation, câble Grove, branchement sur P15:P16, micro:bit correctement insérée, P16/P15 correctement renseignés dans MakeCode.

Étape E

Connecter le module au réseau Wi‑Fi

Ajoutez ensuite le bloc de connexion Wi‑Fi. Il demande deux informations :

SSID = "Nom_du_reseau"
Mot de passe = "Votre_mot_de_passe"

SSID signifie simplement le nom du réseau que vous voyez quand vous cherchez un Wi‑Fi sur votre téléphone ou votre ordinateur.

Pour commencer, utilisez un réseau 2,4 GHz simple. Les réseaux d’établissement avec portail captif, identification web ou WPA Enterprise peuvent empêcher l’ESP8266 de se connecter.
Étape F

Vérifier que le Wi‑Fi fonctionne réellement

Ajoutez un second test :

si Wi‑Fi connecté
    afficher une icône heureuse
sinon
    afficher une croix

Si la connexion réussit, vous avez déjà franchi une étape essentielle :

micro:bit → UART → ESP8266 → Wi‑Fi

Mais aucune donnée n’est encore envoyée vers un site. C’est exactement ce que nous allons faire dans la sous-partie suivante avec ThingSpeak.

À comprendre

Ce qui fonctionne déjà

Le montage sait désormais rejoindre Internet. Il lui manque seulement une destination et une autorisation d’écrire des données. ThingSpeak va fournir ces deux éléments grâce au canal et à la Write API Key.
