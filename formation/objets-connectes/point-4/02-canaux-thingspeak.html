Point 4 · Sous-partie 2

Préparer les 7 canaux ThingSpeak

Pour que le tableau de bord fonctionne facilement, tous les groupes utilisent la même structure de champs.

Structure commune

Même Field = même grandeur

FieldNom conseilléUnité
Field 1Température°C
Field 2Humidité%
Field 3CO₂ppm
Field 4Luminositéselon capteur
Si le groupe 1 utilise Field 1 pour la température, tous les autres groupes font pareil.
Recette

Créer un canal pour chaque groupe

1 — New Channel

Nom : « Station 1 », puis « Station 2 », etc.

2 — Champs

Activez uniquement les grandeurs réellement utilisées.

3 — Save Channel

Enregistrez puis notez le Channel ID.

4 — API Keys

Notez la Write API Key du groupe dans votre fiche privée.

Pourquoi cette rigueur ?

Le site final pourra être générique

field1 → température
field2 → humidité
field3 → CO₂
field4 → luminosité

Le même code HTML pourra lire n’importe quel groupe : seul le Channel ID change.
