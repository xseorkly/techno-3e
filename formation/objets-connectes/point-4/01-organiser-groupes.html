Point 4 · Sous-partie 1

Organiser les 7 groupes

Avant de programmer, on décide qui utilise quel canal. Une organisation claire évite les erreurs de clés et les données mélangées.

Principe

Le professeur gère les comptes, chaque groupe gère son poste

Professeur→Comptes ThingSpeak→7 canaux→7 groupes

Les élèves n’ont pas besoin du mot de passe du compte professeur. Ils reçoivent uniquement les informations nécessaires à leur station.

À vérifier avant la séance

La check-list enseignant

1. Comptes accessibles

Vérifiez que vous pouvez ouvrir ThingSpeak avec vos comptes prévus pour la formation.

2. Canaux créés

Un canal distinct par groupe simplifie l’identification des données.

3. Clés notées

Conservez les Write API Keys dans une feuille privée, jamais dans une page web publique.

4. Numéros de groupes

Étiquetez physiquement les postes 1 à 7 pour éviter les échanges de clés.

Les limites de nombre de canaux et les conditions de licence ThingSpeak peuvent évoluer. Vérifiez votre compte avant la formation au lieu de supposer qu’une répartition donnée sera toujours disponible.
