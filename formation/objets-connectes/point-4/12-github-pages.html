Publier les données des groupes sur GitHub Pages

On part d’un fichier HTML unique. Le professeur remplace seulement les Channel ID publics puis publie la page.

Étape 2

Le seul endroit à modifier

const groupes = [
  { nom: "Groupe 1", channelId: "1234567" },
  { nom: "Groupe 2", channelId: "1234568" },
  { nom: "Groupe 3", channelId: "1234569" }
];
Remplacez les numéros d’exemple par vos Channel ID. Pour cette version simple, utilisez des canaux publics et des données techniques anonymes.

Étape 4

Publier sur GitHub Pages

1 — Créer un dépôt

Exemple : stations-iot.

2 — Ajouter index.html

Collez le code puis remplacez les Channel ID.

3 — Commit

Enregistrez le fichier dans la branche principale.

4 — Settings → Pages

Choisissez la publication depuis la branche principale et le dossier racine.

Après publication, GitHub fournit l’adresse de votre site Pages.

N’insérez pas une Write API Key dans cette page. Pour un canal privé, une Read API Key placée dans un fichier public serait également visible. Le Point 4.13 vous avertira avant tout export.
