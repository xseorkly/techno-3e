Point 4 · Sous-partie 6

Construire un tableau de bord de classe

Le professeur ne veut pas ouvrir sept onglets ThingSpeak. Une page unique rassemble les dernières valeurs de toutes les stations.

Exemple d’affichage

Une carte par groupe

Groupe 1

🌡 22,6 °C

💧 48 %

CO₂ 612 ppm

● données récentes

Groupe 2

🌡 23,1 °C

💧 45 %

CO₂ 681 ppm

● données récentes

Groupe 3

🌡 22,4 °C

💧 51 %

CO₂ 590 ppm

● dernière mesure ancienne

Ce que fera le code

Pour chaque station

1. Lire

Demander la dernière entrée du Channel ID.

2. Extraire

Récupérer field1, field2, field3 et created_at.

3. Afficher

Mettre les valeurs dans la carte du groupe.

4. Actualiser

Recommencer après un délai raisonnable.

Le Point 4.13 fera cela automatiquement : le professeur saisira les Channel ID dans un formulaire et le générateur construira le tableau de bord.
