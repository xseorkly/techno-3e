Générer son tableau de bord sans coder

Entrez les Channel ID ThingSpeak, choisissez ce que vous voulez afficher, prévisualisez puis générez une page HTML autonome prête pour GitHub Pages.

Tout se fait dans votre navigateur. Cette page ne stocke pas vos paramètres. Pour un export GitHub Pages, utilisez de préférence des canaux publics contenant uniquement des données techniques anonymes.

Comprendre les choix

Valeur

Affiche la dernière mesure reçue. Idéal pour savoir « combien maintenant ? ».

Graphique

Affiche l’évolution temporelle via le graphique ThingSpeak.

Valeur + graphique

Associe l’état actuel et l’évolution. C’est le choix le plus complet.

Type du graphique

line, bar, column ou spline selon les types documentés par ThingSpeak.

Canal privé : la prévisualisation locale peut utiliser une Read API Key, mais le générateur refuse de l’insérer silencieusement dans un fichier GitHub public. Une clé placée dans du HTML ou du JavaScript public serait visible.
