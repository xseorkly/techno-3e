Comment une page web lit ThingSpeak

Une API est simplement une porte d’entrée prévue pour qu’un programme demande des données à un service.

La chaîne

Le navigateur demande, ThingSpeak répond

ThingSpeak→API→JSON→JavaScript→HTML
Exemple réel

Lire la dernière mesure

https://api.thingspeak.com/channels/CHANNEL_ID/feeds/last.json

Pour un canal public, cette adresse peut renvoyer directement la dernière entrée. Pour un canal privé, ThingSpeak demande une Read API Key.
