Point 4 · Sous-partie 3

Préparer les programmes des groupes

On ne crée pas sept programmes différents : on prépare un modèle commun et on change seulement l’identifiant nécessaire à chaque station.

Programme commun

La logique reste identique

au démarrage
  initialiser ESP8266 : TX P16 / RX P15 / 115200
  se connecter au Wi‑Fi

toujours
  lire les capteurs
  envoyer les valeurs vers ThingSpeak
  attendre environ 20 s
Ce qui change d’un groupe à l’autre : la Write API Key du canal. Le reste du programme peut être identique.
Exemple

Une clé différente par groupe

Groupe 1

Write Key = CLE_G1

Groupe 2

Write Key = CLE_G2

Groupe 3

Write Key = CLE_G3

Si le groupe 2 utilise par erreur la clé du groupe 1, ses mesures apparaîtront dans le mauvais canal.

Bonne pratique

Tester avant de distribuer

1. Un poste test

Validez complètement le programme sur un seul montage.

2. Dupliquer

Copiez ensuite le programme pour les autres groupes.

3. Modifier la clé

Changez uniquement la Write API Key de chaque copie.

4. Vérifier

Appuyez ou envoyez une mesure et contrôlez le bon canal.
