Point 4 · Sous-partie 4

Donner une fiche simple à chaque groupe

Le groupe doit savoir quoi faire sans recevoir les identifiants du compte enseignant ni des informations inutiles.

Modèle

Fiche « Poste IoT »

POSTE 4 — Station 4

Channel ID : ____________________

Write API Key : ____________________

Field 1 : Température · °C

Field 2 : Humidité · %

Field 3 : CO₂ · ppm

Check-list stagiaire

Je vérifie dans cet ordre

☐ Matériel

micro:bit bien insérée, Grove WiFi sur P15:P16, alimentation ON.

☐ Programme

Extension ESP8266 installée, P16/P15 corrects.

☐ Réseau

SSID et mot de passe saisis, connexion Wi‑Fi obtenue.

☐ ThingSpeak

Bonne Write API Key, mesure visible dans le bon canal.

Ne mettez jamais sur cette fiche le mot de passe du compte ThingSpeak enseignant.
