Situation-problème — « Pourquoi seuls certains postes communiquent ? »

45 min

PC1 et PC2 communiquent. PC3 n’arrive pas à joindre PC1. Le serveur Web est accessible depuis PC1 mais pas depuis le smartphone. Vous disposez du fichier Packet Tracer et de relevés.
Relevé 1
PC1 : 192.168.10.21 /24
PC2 : 192.168.10.22 /24
PC3 : 192.168.20.23 /24
Relevé 2
Smartphone : 192.168.10.80 /24
Passerelle : non renseignée
1. Avant toute manipulation, prédisez quels couples de machines peuvent communiquer directement. Justifiez.
2. Expliquez quelle information du masque /24 vous utilisez.
3. Quelle commande utiliseriez-vous d’abord pour tester la joignabilité ?
4. Si PC1 joint PC2 mais pas PC3, quel équipement devient nécessaire entre les deux réseaux ? Pourquoi ?
5. Le smartphone ne joint pas un serveur situé ailleurs. Quelle configuration manque probablement ?
6. Dans Packet Tracer, observez un paquet en mode Simulation. Notez les équipements traversés puis comparez avec votre prédiction.

Diagnostiquez avant de modifier

1) observez l’adressage ; 2) formulez une hypothèse ; 3) choisissez un test ; 4) observez ; 5) expliquez ; 6) modifiez seulement ensuite.
7. Pourquoi cette démarche est-elle préférable à « cliquez ici, tapez cette IP » ?
Vous reprenez maintenant votre posture d’enseignant

Quatre profils d’élèves

A clique partout ; B attend la procédure ; C comprend le problème mais pas le masque ; D réussit mais ne sait pas expliquer. Pour chacun, proposez l’aide minimale qui permet de reprendre le raisonnement.
Quelle question poseriez-vous à D pour vérifier qu’il a compris et qu’il n’a pas seulement réussi ?
Sciences cognitives

Performance ≠ apprentissage

Une procédure détaillée peut améliorer la réussite immédiate sans construire le raisonnement. Cherchez l’aide minimale qui permet de franchir l’obstacle tout en gardant la responsabilité du diagnostic.
