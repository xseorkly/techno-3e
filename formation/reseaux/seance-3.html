Posture stagiaire : vivre l’activité comme un élève

Situation-problème — « Pourquoi seuls certains postes communiquent ? »

45 min

Dans la salle de technologie, PC1 et PC2 communiquent entre eux. PC3 n’arrive pas à joindre PC1. Le serveur Web est accessible depuis PC1 mais pas depuis le smartphone. Vous disposez du fichier Packet Tracer et de quelques relevés.
Relevé 1
PC1 : 192.168.10.21 /24
PC2 : 192.168.10.22 /24
PC3 : 192.168.20.23 /24
Relevé 2
Smartphone : 192.168.10.80 /24
Passerelle : non renseignée
1. Avant toute manipulation, quels couples de machines pensez-vous pouvoir faire communiquer directement ? Justifiez.
2. Quelle information du masque /24 utilisez-vous pour formuler cette hypothèse ?
3. Quelle commande utiliseriez-vous d’abord pour tester la joignabilité entre deux machines ?
4. Si PC1 peut joindre PC2 mais pas PC3, quel équipement devient nécessaire entre les deux réseaux ? Pourquoi ?
5. Le smartphone est dans le même sous-réseau que PC1, mais ne joint pas le serveur situé ailleurs. Quelle configuration manque probablement ?
6. Dans Packet Tracer, observez un paquet en mode Simulation. Notez les équipements traversés et comparez avec votre prédiction.

Diagnostic guidé, pas recette

Ordre de travail proposé : 1) observer l’adressage ; 2) formuler une hypothèse ; 3) choisir un test ; 4) observer ; 5) expliquer ; 6) seulement ensuite modifier.
7. Pourquoi cette démarche est-elle préférable à « cliquez ici, tapez cette IP » ?
Changement de posture : enseignant

Quatre profils d’élèves

A clique partout ; B attend la procédure ; C comprend le problème mais pas le masque ; D réussit mais ne sait pas expliquer. Pour chacun, quelle aide minimale proposer ?
Quelle question permettrait de vérifier que D a compris et n’a pas seulement réussi ?
Sciences cognitives

Performance ≠ apprentissage

Une procédure détaillée améliore souvent la réussite immédiate. Mais elle peut réduire le besoin de raisonner. Le bon étayage donne juste assez d’aide pour que l’élève puisse franchir l’obstacle tout en conservant la responsabilité du diagnostic.
