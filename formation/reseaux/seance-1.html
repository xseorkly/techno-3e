Situation-problème — « Le site existe… mais où est-il ? »

35 min

Contexte. Vous devez consulter le site du musée des sciences. Sur un poste, https://musee-exemple.fr s’ouvre. Sur un autre, le navigateur affiche « serveur introuvable ». Pourtant les deux postes sont connectés au même réseau et peuvent échanger des fichiers locaux. Qu’est-ce qui peut expliquer qu’un nom de site fonctionne sur un poste et pas sur l’autre ?

Passerelle 192.168.1.1
DNS 192.168.1.10
Document B
Poste 2 : IP 192.168.1.25
Passerelle 192.168.1.1
DNS : non renseigné
1. Comparez les deux configurations. Quelles informations sont identiques ? Qu’est-ce qui diffère ?
2. Choisissez l’hypothèse la plus plausible et justifiez.
3. Faites une prédiction : si vous saisissez directement l’adresse IP du serveur, que devrait-il se passer ? Pourquoi ?
4. Formulez en une phrase le rôle du DNS, sans utiliser le mot « traduction ».

Deuxième situation — Internet ou Web ?

Le Wi‑Fi fonctionne. Vous pouvez envoyer un message dans une application, mais aucune page Web ne s’ouvre. Quelqu’un affirme : « Internet est coupé ». Cette conclusion est-elle nécessairement correcte ?
5. Repérez les services qui peuvent utiliser Internet sans être le Web : courriel, visioconférence, jeu en ligne, page Web, DNS.
6. Complétez avec vos mots : Internet est… / Le Web est…

Sciences cognitives

Connaissances antérieures et point aveugle de l’expert

Vous avez d’abord mobilisé vos propres représentations. Un novice peut regrouper réseau local, Internet, Web et DNS dans une seule idée de « connexion ».

À retenir : faites émerger la représentation initiale avant de formaliser. Vous saurez ainsi ce qu’il faut réellement reconstruire.
