Posture stagiaire : vivre l’activité comme un élève

Situation-problème — « Le site existe… mais où est-il ? »

35 min

Contexte. Une classe doit consulter le site du musée des sciences. Sur un poste, https://musee-exemple.fr s’ouvre. Sur un autre, le navigateur affiche « serveur introuvable ». Pourtant les deux postes sont connectés au même réseau et peuvent échanger des fichiers locaux. Le professeur demande : « Qu’est-ce qui peut expliquer qu’un nom de site fonctionne sur un poste et pas sur l’autre ? »
Document A
Poste 1 : IP 192.168.1.24
Passerelle 192.168.1.1
DNS 192.168.1.10
Document B
Poste 2 : IP 192.168.1.25
Passerelle 192.168.1.1
DNS : non renseigné
1. Quelles informations sont identiques sur les deux postes ? Qu’est-ce qui diffère ?
2. Parmi les hypothèses suivantes, laquelle paraît la plus plausible ? Justifiez.
3. Prédisez : si on saisit directement l’adresse IP du serveur dans le navigateur, que devrait-il se passer ? Pourquoi ?
4. Formulez en une phrase le rôle du DNS, sans utiliser le mot « traduction ».

Deuxième situation — Internet ou Web ?

Le Wi-Fi du collège fonctionne. Un élève peut envoyer un message dans une application, mais aucune page Web ne s’ouvre. Il affirme : « Internet est coupé ». A-t-il nécessairement raison ?
5. Parmi ces services, lesquels peuvent utiliser Internet sans être le Web : courriel, visioconférence, jeu en ligne, page Web, DNS ?
6. Complétez : Internet est… / Le Web est…

Sciences cognitives

Connaissances antérieures et point aveugle de l’expert

Le stagiaire a d’abord dû mobiliser ses propres représentations. La difficulté vient moins du vocabulaire que du modèle mental : un expert distingue spontanément réseau local, Internet, Web et DNS ; un novice peut les confondre dans une seule idée de « connexion ».

Principe à retenir : faire émerger la représentation initiale avant de formaliser permet de savoir ce qu’il faut réellement reconstruire.
