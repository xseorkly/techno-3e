Observer une rotation avec l’IMU

Comment le robot sait-il de quel angle il a tourné ?

← FormationAccueil mBot21 · Démarrer2 · Les fichesGlossaireDépannage
En une phrase

Le CyberPi affiche l’angle dont il a tourné autour de la verticale. Vous le faites pivoter à la main et le nombre change.

Durée estimée (essais et bilan compris)
15 min
Difficulté
●●●
Matériel
CyberPi (capteur de mouvement intégré). Pas besoin de rouler.
Lancement
Automatique : dès que le programme démarre sur le robot
Avant de commencer

Votre check-list

  • Le robot est allumé et sa batterie est chargée.
  • mBlock 5 est ouvert et le CyberPi est connecté (voir Démarrer).
  • Le mode « Téléverser » est choisi, pour que le robot garde le programme et réagisse à ses boutons A et B.

Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme mBlock est un empilement de blocs, à lire de haut en bas. Chaque bloc a une couleur qui indique son rôle. Voici chaque bloc de cette fiche, dans l’ordre, expliqué simplement.

DépartContrôleAction du robotInformationÉcranMémoireCalcul

Les couleurs ci-dessous sont proches de celles de mBlock. Les blocs sont redessinés ici pour être lisibles ; la vraie capture d’écran est plus bas.

Le seul programme

1
lorsque CyberPi démarreDépart

Ce que fait ce bloc : Départ : le programme démarre tout seul.

Pourquoi il est là : Aucun bouton à presser : on veut observer.

2
réinitialiser l’angle de rotation autour de l’axe tous ▾Information

Ce que fait ce bloc : Remet à zéro les angles mesurés par le capteur de mouvement : la position actuelle devient « 0° ».

Pourquoi il est là : On veut mesurer l’angle de rotation à partir de maintenant, pas depuis l’allumage.

Mot à connaître. L’IMU (capteur de mouvement) est la petite puce du CyberPi qui sent ses rotations et ses inclinaisons.

3
pour toujoursContrôle

Ce que fait ce bloc : Répète sans fin.

Pourquoi il est là : Pour mettre à jour l’affichage en continu.

4
effacer l’écranÉcran

Ce que fait ce bloc : Vide l’écran.

Pourquoi il est là : Pour n’afficher que la valeur la plus récente.

5
afficher le texte angle de rotation autour de l’axe z ▾ (°) et sauter une ligneÉcran

Ce que fait ce bloc : Écrit sur l’écran l’angle dont le CyberPi a tourné autour de l’axe z (l’axe vertical), en degrés.

Pourquoi il est là : C’est ce qui permet de lire la rotation du robot : si vous tournez le robot de 90° à la main, vous lisez environ 90.

Dans ce bloc, il y a :

  • axe zL’axe vertical (comme une broche qui traverse le robot de haut en bas). Tourner à plat sur la table fait changer l’angle z.

Mot à connaître. Un « axe » est une direction de référence : x, y et z sont les trois directions de l’espace.

6
attendre 0.2 secsContrôle

Ce que fait ce bloc : Pause de 0,2 seconde.

Pourquoi il est là : Pour que l’affichage soit lisible.

Le programme en français

Le même programme, sans les blocs

C’est exactement ce que fait le programme, écrit avec des phrases. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’un choix.

Quand le programme démarre :
   1. je remets à zéro l’angle de rotation ;
   2. je répète sans fin :
         a. j’efface l’écran ;
         b. j’écris l’angle de rotation autour de l’axe z ;
         c. j’attends 0,2 seconde.

Essayez

Testez pas à pas

  1. Posez le CyberPi à plat sur la table et lancez le programme.
  2. Faites-le pivoter à la main d’un quart de tour : lisez le nombre.
  3. Faites un demi-tour, puis un tour complet.
  4. Comparez avec les angles attendus (90, 180, 360).
Ce que vous devez observer : Le nombre affiché suit votre rotation, avec une petite imprécision.

Si ça ne marche pas

  • Le nombre dérive tout seul. Le capteur de mouvement peut dériver légèrement avec le temps. Relancez le programme pour remettre à zéro.
  • Le nombre ne change pas. Tournez bien autour de l’axe vertical, à plat.

Autres solutions : voir la page Dépannage. Ces fiches n’ont pas été testées avec un robot réel : vos observations peuvent différer légèrement.

Pour comprendre

Modifiez une chose, observez ce qui change

Pour être sûr d’avoir compris, changez un seul élément, prévoyez le résultat, puis vérifiez avec le robot.

  • Remplacez l’axe z par x ou y : que mesure-t-on alors ?
  • Lancez, tournez de 90° puis retournez à la position de départ : lit-on 0 ?
Pour la classe (facultatif)Utiliser cette fiche avec des élèves
  • Objectif élève : comprendre qu’un robot peut mesurer sa propre rotation.
  • Faites prédire l’angle avant chaque rotation.
  • Trace attendue : tableau « rotation réelle / angle lu ».
