Observer les états des sondes L1 et R1

Comment passer d’une piste au sol à une information utilisable ?

En une phrase

Le robot affiche en continu un nombre qui dit si les deux sondes centrales du capteur de ligne voient la ligne noire ou le fond clair.

Durée estimée (essais et bilan compris)
20 min
Difficulté
●●●
Matériel
mBot2 avec capteur Quad RGB (numéro 1) sous le robot, piste noire sur fond clair (ruban adhésif noir)
Lancement
Automatique : dès que le programme démarre sur le robot
Avant de commencer

Votre check-list

  • Le robot est allumé et sa batterie est chargée.
  • mBlock 5 est ouvert et le CyberPi est connecté (voir Démarrer).
  • Le mode « Téléverser » est choisi, pour que le robot garde le programme et réagisse à ses boutons A et B.
  • Matériel de cette fiche : mBot2 avec capteur Quad RGB (numéro 1) sous le robot, piste noire sur fond clair (ruban adhésif noir).
Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme mBlock est un empilement de blocs, à lire de haut en bas. Chaque bloc a une couleur qui indique son rôle. Voici chaque bloc de cette fiche, dans l’ordre, expliqué simplement.

DépartContrôleAction du robotInformationÉcranMémoireCalcul

Les couleurs ci-dessous sont proches de celles de mBlock. Les blocs sont redessinés ici pour être lisibles ; la vraie capture d’écran est plus bas.

Le seul programme

1
lorsque CyberPi démarreDépart

Ce que fait ce bloc : Bloc de départ : lancement dès que le programme démarre sur le robot.

Pourquoi il est là : Aucun appui nécessaire : on veut seulement lire le capteur.

2
pour toujoursContrôle

Ce que fait ce bloc : Répète sans fin les blocs à l’intérieur.

Pourquoi il est là : Le capteur doit être lu sans cesse pour suivre vos déplacements.

3
effacer l’écranÉcran

Ce que fait ce bloc : Vide l’écran.

Pourquoi il est là : Pour n’afficher que la dernière valeur lue.

4
afficher le texte capteur quad RGB 1 ▾ état de L1 et R1 en mode ligne ▾ (0~3) et sauter une ligneÉcran

Ce que fait ce bloc : Écrit sur l’écran un nombre entre 0 et 3 qui résume ce que voient les deux sondes centrales L1 et R1.

Pourquoi il est là : C’est une « fenêtre » sur ce que voit le capteur : vous voyez enfin ce qu’il détecte, ce qui est invisible autrement.

Dans ce bloc, il y a :

  • capteur quad RGB 1Le capteur de ligne placé sous le robot. Il contient 4 petites sondes (L2, L1, R1, R2) qui regardent le sol.
  • état de L1 et R1 en mode ligne (0~3)Un nombre de 0 à 3 : il change selon que L1 et/ou R1 voient la ligne ou le fond. Le tableau ci-dessous vous fait découvrir sa signification.

Mot à connaître. Une « sonde » est un petit œil du capteur. L1 = sonde gauche du centre, R1 = sonde droite du centre.

5
attendre 0.2 secsContrôle

Ce que fait ce bloc : Pause de 0,2 seconde.

Pourquoi il est là : Pour que le nombre reste lisible.

Le programme en français

Le même programme, sans les blocs

C’est exactement ce que fait le programme, écrit avec des phrases. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’un choix.

Quand le programme démarre :
   je répète sans fin :
      1. j’efface l’écran ;
      2. j’écris le nombre (0 à 3) qui décrit ce que voient L1 et R1 ;
      3. j’attends 0,2 seconde.

Essayez

Testez pas à pas

  1. Préparez le capteur : posez-le sur le fond clair, appuyez deux fois sur son bouton, puis passez-le d’un côté à l’autre de la ligne jusqu’à la fin du clignotement (voir « Préparer »).
  2. Envoyez le programme au robot.
  3. Placez le robot : L1 et R1 sur le fond clair ; puis L1 sur la ligne ; puis R1 sur la ligne ; puis les deux sur la ligne.
  4. Notez le nombre affiché dans chaque situation pour compléter votre tableau.
Ce que vous devez observer : Le nombre affiché change selon la position du robot par rapport à la ligne. À vous de remplir le tableau « situation → nombre » : c’est le but de la fiche.

Si ça ne marche pas

  • Le nombre reste toujours le même. Vérifiez que l’apprentissage ligne/fond du capteur a bien été fait et que la piste est contrastée (noir sur clair).
  • Les valeurs varient bizarrement. Le capteur doit rester à hauteur constante au-dessus du sol.

Autres solutions : voir la page Dépannage. Ces fiches n’ont pas été testées avec un robot réel : vos observations peuvent différer légèrement.

Pour comprendre

Modifiez une chose, observez ce qui change

Pour être sûr d’avoir compris, changez un seul élément, prévoyez le résultat, puis vérifiez avec le robot.

  • Complétez un tableau : L1 et R1 sur fond / L1 sur ligne / R1 sur ligne / les deux sur ligne → quel nombre ?
  • Changez le mode « ligne » pour un autre mode du menu et comparez.
Pour la classe (facultatif)Utiliser cette fiche avec des élèves
  • Objectif élève : lire l’information d’un capteur avant de l’utiliser dans une décision.
  • Faites remplir le tableau situation / nombre avant toute programmation.
  • Trace attendue : tableau complété et phrase de conclusion.
