Afficher un message sur CyberPi

Comment savoir que mon ordinateur et mon robot se comprennent ?

⏱ 5 minDifficulté ●●●
Avant de commencer
  • Le robot est allumé, batterie chargée.
  • mBlock 5 est ouvert et le CyberPi est connecté (voir Démarrer).
  • Matériel : CyberPi seul (roues et capteurs inutiles).
1

Prédire

Avant de regarder le programme, écrivez en une phrase ce que vous pensez que le robot va faire. Lancement : Automatique : dès que le programme démarre sur le robot.

Se tromper ici est utile : c’est ce qui fait apprendre.

2

Lire le programme

Le robot écrit « Bonjour CyberPi ! » sur son petit écran. C’est le tout premier test : s’il fonctionne, votre ordinateur et votre robot se comprennent.

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’un choix.

Quand le programme démarre :
   1. j’efface l’écran du CyberPi ;
   2. j’écris « Bonjour CyberPi ! » sur l’écran.
Comprendre chaque bloc (facultatif)

Le seul programme

1
lorsque CyberPi démarreDépart

Ce que fait ce bloc : Bloc de départ. Il veut dire : « dès que le programme démarre sur le robot, fais tout ce qui est accroché en dessous ».

Pourquoi il est là : Un programme commence toujours par un bloc jaune de ce type. Sans lui, les blocs du dessous ne s’exécuteraient jamais, comme une recette que personne ne commence.

Mot à connaître. Un « événement » est quelque chose qui se produit (ici : le démarrage) et qui déclenche la suite.

À savoir. Ce bloc n’a rien à voir avec le bouton A : il part tout seul.

2
effacer l’écranÉcran

Ce que fait ce bloc : Vide l’écran du CyberPi pour avoir une page blanche.

Pourquoi il est là : Sans lui, un ancien texte pourrait rester affiché derrière le nouveau.

3
afficher le texte Bonjour CyberPi !Écran

Ce que fait ce bloc : Écrit sur l’écran du CyberPi le texte placé dans la case blanche, exactement comme il a été tapé.

Pourquoi il est là : C’est le résultat visible du programme : la preuve que le robot a reçu vos blocs et les a exécutés.

3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Dans mBlock : « Fichier » → « Ouvrir à partir de votre ordinateur », puis choisissez le fichier.
  3. 3
    Vérifiez que le CyberPi est connecté, choisissez le mode « Téléverser », puis cliquez sur le bouton d’envoi. Première fois ? Voir Démarrer.

Essayer

  1. 1
    Ouvrez le fichier 01 dans mBlock et vérifiez que le CyberPi est connecté (page « Démarrer »).
  2. 2
    Choisissez le mode « Téléverser », puis envoyez le programme au robot.
  3. 3
    Regardez l’écran du CyberPi, pas celui de l’ordinateur.
  4. 4
    Dans la case blanche du dernier bloc, remplacez le texte par votre prénom, puis envoyez à nouveau.
Ce que vous devez observer : Le texte « Bonjour CyberPi ! » (puis votre prénom) apparaît sur l’écran du CyberPi.
Si ça ne marche pas
  • Rien ne s’affiche. Vérifiez d’abord la connexion et le mode. Ce fichier a été enregistré en mode « En direct » : passez en « Téléverser » puis envoyez le programme. Un écran vide ne veut pas dire que le robot est cassé.
  • mBlock ne trouve pas le CyberPi. Voir la page Dépannage : câble, robot allumé, nouvelle tentative de connexion.

Autres solutions : page Besoin d’aide ?

4

Expliquer

Changez un seul élément, prévoyez le résultat, puis vérifiez avec le robot.

  • Remplacez le texte par votre prénom.
  • Supprimez le bloc « effacer l’écran » puis relancez : voyez-vous une différence ?
5

Et dans ma classe ?

  • Objectif élève : comprendre qu’un programme part d’un événement et s’exécute dans l’ordre, de haut en bas.
  • Vous pouvez donner les trois blocs mélangés et demander de les remettre dans l’ordre.
  • Trace attendue : une phrase « Quand …, le robot … ». Cet exercice ne valide pas encore un déplacement.
