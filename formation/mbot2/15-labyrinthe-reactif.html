Analyser une stratégie réactive de labyrinthe

Comment un robot peut-il se sortir d’un couloir sans carte ?

← FormationAccueil mBot21 · Démarrer2 · Les fichesGlossaireDépannage
En une phrase

Le robot avance. S’il voit un mur à moins de 20 cm, il recule, tourne à gauche, puis revérifie : si c’est encore bloqué, il se retourne de l’autre côté. Il découvre ainsi le chemin sans carte.

Durée estimée
30 min
Difficulté
●●●
Matériel
mBot2 avec capteur ultrason (numéro 1), parois de carton formant un couloir avec un cul-de-sac
Lancement
A lance le programme ; B arrête le robot
Avant de commencer

Votre check-list

  • Le robot est allumé et sa batterie est chargée.
  • mBlock 5 est ouvert et le CyberPi est connecté (voir Démarrer).
  • Le mode « Téléverser » est choisi, pour que le robot garde le programme et réagisse à ses boutons A et B.

Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme mBlock est un empilement de blocs, à lire de haut en bas. Chaque bloc a une couleur qui indique son rôle. Voici chaque bloc de cette fiche, dans l’ordre, expliqué simplement.

DépartContrôleAction du robotInformationÉcranMémoireCalcul

Les couleurs ci-dessous sont proches de celles de mBlock. Les blocs sont redessinés ici pour être lisibles ; la vraie capture d’écran est plus bas.

Script 1 — Quand on appuie sur A (explorer)

1
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : le programme se lance quand on appuie sur le bouton A du CyberPi, comme dans les fiches précédentes.

Pourquoi il est là : Vous choisissez le moment du départ.

2
pour toujoursContrôle

Ce que fait ce bloc : Répète sans fin ce qui est à l’intérieur.

Pourquoi il est là : Le robot teste son environnement en permanence.

3
si capteur ultrason 1 ▾ : distance jusqu’à l’objet (cm) < 20 alors … sinon …Contrôle

Ce que fait ce bloc : Décision principale : mur proche ou non.

Pourquoi il est là : Le robot n’a pas de carte, il réagit seulement à ce qu’il mesure maintenant : c’est une stratégie « réactive ».

Mot à connaître. « Réactive » = le robot réagit à la situation présente, sans mémoire ni plan.

4
arrêter le moteur encodeur tout ▾Action du robot

Ce que fait ce bloc : Arrête les moteurs.

Pourquoi il est là : Il faut s’arrêter avant de manœuvrer.

5
reculer ▾ 10 cm ▾ jusqu’à la finAction du robot

Ce que fait ce bloc : Recule de 10 cm.

Pourquoi il est là : Prendre de la distance avec le mur pour pouvoir tourner.

6
tourner à gauche ▾ 90 ° jusqu’à la finAction du robot

Ce que fait ce bloc : Tourne d’un quart de tour pour regarder ailleurs.

Pourquoi il est là : Première tentative : tenter de passer sur le côté.

7
si capteur ultrason 1 ▾ : distance jusqu’à l’objet (cm) < 20 alorsContrôle

Ce que fait ce bloc : Deuxième vérification : après ce virage, est-ce encore bloqué ?

Pourquoi il est là : Si c’est encore bloqué, c’est sans doute un cul-de-sac : il faut changer de stratégie.

8
tourner à droite ▾ 180 ° jusqu’à la finAction du robot

Ce que fait ce bloc : Fait un demi-tour vers la droite.

Pourquoi il est là : Après le virage à gauche, un demi-tour vers la droite oriente le robot vers l’autre côté, vers la sortie possible.

À savoir. Depuis la direction d’origine : gauche 90°, puis droite 180° = au final 90° vers la droite.

9
sinonContrôle

Ce que fait ce bloc : Si le passage est libre au premier test (pas de mur proche).

Pourquoi il est là : Cas normal : avancer.

10
avancer ▾ à 30 tr/minAction du robot

Ce que fait ce bloc : Roule vers l’avant.

Pourquoi il est là : Tant que rien ne bloque, le robot avance.

Script 2 — Quand on appuie sur B (l’arrêt)

11
lorsque le bouton B ▾ est presséDépart

Ce que fait ce bloc : Départ de l’arrêt.

Pourquoi il est là : Pour stopper à tout moment.

12
arrêter le moteur encodeur tout ▾Action du robot

Ce que fait ce bloc : Coupe les moteurs.

Pourquoi il est là : Le robot s’immobilise.

13
arrêt tout ▾Contrôle

Ce que fait ce bloc : Arrête tous les scripts.

Pourquoi il est là : Sans cela, la boucle relancerait les moteurs.

Le programme en français

Le même programme, sans les blocs

C’est exactement ce que fait le programme, écrit avec des phrases. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’un choix.

Quand j’appuie sur A :
   je répète sans fin :
      si la distance mesurée est inférieure à 20 cm :
         1. j’arrête les moteurs ; je recule de 10 cm ; je tourne de 90° ;
         2. si la distance est encore inférieure à 20 cm :
               je tourne de 180° de l’autre côté ;
      sinon :
         j’avance à 30 tr/min.
Quand j’appuie sur B :
   j’arrête les moteurs et tous les scripts.

Essayez

Testez pas à pas

  1. Construisez un couloir avec un cul-de-sac (parois de carton).
  2. Vérifiez B avant tout.
  3. Lancez avec A et observez les réactions du robot à chaque obstacle.
  4. Notez les situations où il se trompe ou se bloque.
Ce que vous devez observer : Le robot traverse plus de situations que le programme 08, mais il peut encore se perdre : sans carte, il ne garantit pas de trouver la sortie.

Si ça ne marche pas

  • Il tourne en rond. Le programme est réactif : certains labyrinthes le piègent. C’est une limite à discuter.
  • Il cogne les parois. Augmentez le seuil (par exemple 25).

Autres solutions : voir la page Dépannage. Ces fiches n’ont pas été testées avec un robot réel : vos observations peuvent différer légèrement.

Pour comprendre

Modifiez une chose, observez ce qui change

Pour être sûr d’avoir compris, changez un seul élément, prévoyez le résultat, puis vérifiez avec le robot.

  • Changez le seuil 20 en 30 pour les deux conditions.
  • Remplacez 180 par 90 : le comportement change-t-il ?
