Matériel indispensable

  • Un Maqueen classique ROB0148, une carte micro:bit et l’alimentation adaptée au châssis.
  • Un câble USB capable de transférer des données.
  • Un ordinateur avec un navigateur récent ; aucun compte n’est nécessaire pour les opérations décrites.

Importer un véritable projet fourni

  1. Télécharger le fichier .hex d’une fiche.
  2. Ouvrir Microsoft MakeCode micro:bit, revenir à l’accueil et choisir Importer.
  3. Choisir Importer un fichier et sélectionner le HEX. MakeCode retrouve le projet et ses dépendances.
  4. Ouvrir l’onglet Blocs. Les blocs Maqueen se trouvent dans Maqueen v4.
  5. Modifier un seul réglage, télécharger le nouveau HEX puis le copier sur le disque MICROBIT.

Créer un projet à partir de zéro

  1. À l’accueil MakeCode, choisir Nouveau projet et lui donner un nom explicite.
  2. Dans la boîte à outils, choisir Extensions.
  3. Rechercher https://github.com/DFRobot/pxt-maqueen et sélectionner maqueen.
  4. Pour le classique, choisir Maqueen v4. L’extension affiche aussi Maqueen v5 : ne pas mélanger ces API.
  5. Assembler les blocs ou coller le fichier .ts dans JavaScript, puis revenir à Blocs. Le fichier .ts seul n’inclut pas les dépendances : ajouter l’extension avant de le coller.

Comprendre l’anomalie de traduction

Lire les captures françaises sans se tromper. La traduction actuelle de DFRobot inverse les libellés : « arrière » correspond à CW (Forward dans le code officiel) et « avant » à CCW (Backward). Les fichiers fournis utilisent CW pour avancer. Importez le HEX plutôt que de reconstruire le programme en vous fiant uniquement aux mots avant/arrière. Vérifiez le sens des roues levées avant tout essai. Voir l’explication et la source.

Le code officiel définit CW = 0 comme Forward et CCW = 1 comme Backward. Son fichier français traduit CW par arrière et CCW par avant. Ce sont les libellés qui divergent, pas les constantes des fichiers fournis.

Pour reconstruire les blocs en français dans cette version : choisir le libellé arrière pour CW et avant pour CCW. Si la traduction est corrigée ultérieurement, se référer aux constantes ou importer le HEX. Source de la traduction.

Transférer et vérifier

  1. Brancher la carte en USB et vérifier le disque MICROBIT.
  2. Copier le HEX sur ce disque ; attendre la fin du clignotement.
  3. Le HEX peut disparaître de la liste : ce disque sert au transfert, ce n’est pas un stockage ordinaire.
  4. Placer la carte dans le châssis suivant son détrompage ; couper l’alimentation pendant l’insertion.
  5. Allumer le châssis et tester la fiche 01, puis la fiche 02 roues levées.

Le simulateur montre la carte micro:bit. Il ne remplace pas un essai du robot et ne valide pas ses distances réelles.
