Éviter un obstacle

Éviter un obstacle, est-ce connaître le bon chemin ?

⏱ 25 minDifficulté ●●●
Votre mission

À l’appui sur A, le robot mesure une fois. S’il voit un obstacle à 20 cm ou moins, il recule un peu puis tourne à droite. Sinon il reste arrêté.

Matériel : Maqueen avec ultrason, carton, zone dégagée (derrière aussi)

À la fin, je saurai :

  • Je sais enchaîner plusieurs actions dans une manœuvre.
  • Je vois les limites d’une manœuvre sans surveillance continue.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Que fera le robot si l’obstacle est à 40 cm ?
  2. Pourra-t-il éviter un mur long ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Quand j’appuie sur A :
   je mesure la distance ;
   si la mesure est valide et ≤ 20 cm :
      je recule 300 ms, j’arrête, je pivote 400 ms vers la droite, j’arrête ;
   sinon : je reste arrêté.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

3
définir distance ▾ à Lire la distance du capteur à ultrasons (en cm)Mémoire

Ce que fait ce bloc : Mesure la distance une seule fois.

Pourquoi il est là : Une mesure unique, au moment de l’appui.

4
si distance valide et distance ≤ 20 alors … sinon …Contrôle

Ce que fait ce bloc : Si l’obstacle est proche et la mesure valide, il manœuvre ; sinon il ne fait rien.

Pourquoi il est là : La condition « valide » évite d’agir sur une fausse mesure (0 ou 500).

5
Moteur Tous ▾ dir avant ▾ vitesse 60 ⚠ fait RECULERMoteurs

Ce que fait ce bloc : Les deux roues tournent pour reculer.

Pourquoi il est là : On s’éloigne de l’obstacle pour avoir de la place.

6
pause (ms) 300Contrôle

Ce que fait ce bloc : Le programme attend 300 millisecondes (soit 0.3 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Durée du recul.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

7
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Fin du recul.

8
Moteur M1 ▾ dir arrière ▾ vitesse 60 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : La roue gauche (M1) tourne dans le sens qui fait avancer, à la puissance 60.

Pourquoi il est là : Le robot commence à tourner.

9
Moteur M2 ▾ dir avant ▾ vitesse 60 ⚠ fait RECULERMoteurs

Ce que fait ce bloc : La roue droite (M2) tourne dans le sens contraire (elle recule), à la puissance 60.

Pourquoi il est là : Une roue qui avance et l’autre qui recule : le robot tourne sur place vers la droite, comme un char.

10
pause (ms) 400Contrôle

Ce que fait ce bloc : Le programme attend 400 millisecondes (soit 0.4 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Durée du quart de tour.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

11
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Fin du virage.

12
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Si pas d’obstacle, on reste arrêté.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
input.onButtonPressed(Button.A, function () {
let distance = maqueen.Ultrasonic()
if (distance > 0 && distance < 500 && distance <= 20) {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CCW, 60)
basic.pause(300)
maqueen.motorStop(maqueen.Motors.All)
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 60)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CCW, 60)
basic.pause(400)
maqueen.motorStop(maqueen.Motors.All)
} else {
maqueen.motorStop(maqueen.Motors.All)
}
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Placez un carton à 15 cm, dégagez l’arrière.
  2. 2
    Appuyez sur A : observez le recul puis le virage.
  3. 3
    Recommencez avec un carton à 40 cm : rien ne doit bouger.
Ce que vous devez observer : Recul, puis virage vers la droite. À 40 cm, rien ne se passe.

À retenir : ce programme fait une manœuvre après une seule mesure (il recule, puis tourne). Ce n’est pas un évitement continu. Cette simplification convient si l’élève doit comprendre « une condition déclenche une séquence ». Pour un évitement réel, il faut mesurer en boucle pendant la rotation. Choisissez ce que vous voulez faire apprendre avant de choisir la version.

Si ça ne marche pas
  • Il ne recule pas. Obstacle trop loin ou mesure invalide : testez avec un carton plat à 15 cm.
  • Il heurte un mur à l’arrière. Il n’a pas de capteur arrière : dégagez la zone.

Autres solutions : page Besoin d’aide ?

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Faites tourner le robot vers la gauche.
  • Augmentez la durée du recul à 600 ms.

Et dans ma classe ?

Ce que l’élève apprend
Isoler une manœuvre avant de construire un comportement autonome.
Ce que je donne
La séquence ; les élèves la rendent permanente (voir activité 14).
Piège à anticiper
Penser que le robot « voit » tout : il ne mesure que devant.
Trace écrite attendue
Un schéma des trois phases : mesurer, reculer, tourner.
