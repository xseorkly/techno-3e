Avancer pendant une seconde

Si je commande 1 seconde, le robot parcourt-il toujours la même distance ?

⏱ 20 minDifficulté ●●●
Votre mission

Quand on appuie sur A, le robot avance en ligne droite pendant 1 seconde, puis s’arrête. On mesure ensuite la distance réelle.

Matériel : Maqueen monté, sol plat dégagé, mètre, ruban

À la fin, je saurai :

  • Je sais faire avancer le robot.
  • Je comprends qu’une durée n’est pas une distance.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Quelle distance va parcourir le robot ? Notez une estimation en cm.
  2. Si je recommence 3 fois, aurai-je trois fois le même résultat ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Au démarrage : j’arrête les moteurs.
Quand j’appuie sur A :
   1. je fais avancer les deux roues à la puissance 80 ;
   2. j’attends 1000 ms ;
   3. j’arrête les moteurs.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

3
Moteur Tous ▾ dir arrière ▾ vitesse 80 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : Fait tourner les deux roues dans le même sens, à la puissance 80. Le robot roule tout droit.

Pourquoi il est là : Le robot démarre : les deux roues tournent à la même puissance.

Dans ce bloc, il y a :

  • Tous ▾Les deux moteurs à la fois (M1 = gauche, M2 = droite).
  • dir arrière ⚠ fait AVANCERLe sens de rotation. Piège : dans la version française de MakeCode, « arrière » est en réalité le sens qui fait AVANCER le robot (erreur de traduction connue). Les programmes fournis sont corrects.
  • 80La puissance, de 0 à 255. Ce n’est pas une vitesse en cm/s.

À savoir. Le moteur continue de tourner tant qu’aucun autre ordre n’arrive (pause, stop…).

4
pause (ms) 1000Contrôle

Ce que fait ce bloc : Le programme attend 1000 millisecondes (soit 1 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Le robot roule pendant que le programme attend. C’est cette attente qui fixe la durée du déplacement.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

5
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Sans ce bloc, le robot ne s’arrêterait jamais : la pause seule ne coupe pas les moteurs.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
input.onButtonPressed(Button.A, function () {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 80)
basic.pause(1000)
maqueen.motorStop(maqueen.Motors.All)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Levez le robot : appuyez sur A et vérifiez que les deux roues tournent dans le sens de l’avance.
  2. 2
    Posez-le au sol, repérez son point de départ (ruban).
  3. 3
    Appuyez sur A et mesurez la distance parcourue.
  4. 4
    Recommencez trois fois et notez les trois mesures.
Ce que vous devez observer : Le robot avance un moment puis s’arrête. Vos trois distances sont proches mais pas identiques.
Si ça ne marche pas
  • Le robot recule. Les roues sont peut-être branchées dans l’autre sens : relancez le fichier fourni et vérifiez roues levées.
  • Il dévie. Contrôlez le sol, la batterie et les roues. Un léger écart est normal.

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Passez à 1500 ms : prévoyez la nouvelle distance avant d’essayer.
  • Passez la puissance à 120 : la distance change-t-elle ?

Et dans ma classe ?

Annoncer « le robot avance de 50 cm » : la consigne est une durée.

Tableau de trois essais avec unité, et une conclusion.
