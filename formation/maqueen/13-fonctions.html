② Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme est un empilement de blocs, à lire de haut en bas. La couleur d’un bloc indique son rôle. Chaque bloc est expliqué dans l’ordre.

DépartContrôleMoteursCapteurAffichage / LEDMémoireCalculMa fonctionCommunication

Les blocs ci-dessous sont redessinés pour être lisibles ; la vraie capture de MakeCode est plus bas. Les libellés peuvent différer légèrement selon la version de MakeCode.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
définir coteMs ▾ à 1000Mémoire

Ce que fait ce bloc : Durée d’un côté, en ms.

Pourquoi il est là : Réglage rangé en haut du programme : on ne cherche plus dans les blocs.

3
définir virageMs ▾ à 400Mémoire

Ce que fait ce bloc : Durée d’un virage.

Pourquoi il est là : Même idée.

4
définir nombreCotes ▾ à 4Mémoire

Ce que fait ce bloc : Nombre de côtés.

Pourquoi il est là : Pour changer de figure.

5
fonction avancerMa fonction

Ce que fait ce bloc : Définit un nouveau bloc « avancer » : avance pendant coteMs, puis arrête.

Pourquoi il est là : Le nom explique l’action : le programme principal devient lisible.

Mot à connaître. Une fonction est un groupe de blocs auquel on donne un nom.

6
fonction tournerDroiteMa fonction

Ce que fait ce bloc : Définit « tournerDroite » : pivot vers la droite pendant virageMs.

Pourquoi il est là : Même intérêt.

7
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

8
répéter nombreCotes foisContrôle

Ce que fait ce bloc : Répète autant de fois que de côtés.

Pourquoi il est là : La boucle s’adapte au réglage.

9
appeler avancerMa fonction

Ce que fait ce bloc : Exécute la fonction « avancer ».

Pourquoi il est là : On lit l’intention, pas les détails.

10
appeler tournerDroiteMa fonction

Ce que fait ce bloc : Exécute la fonction « tournerDroite ».

Pourquoi il est là : Idem.

Le programme en français

Le même programme, avec des phrases

Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Réglages : coteMs = 1000, virageMs = 400, nombreCotes = 4.
Fonction avancer : j’avance coteMs ms puis j’arrête.
Fonction tournerDroite : je pivote virageMs ms puis j’arrête.
Quand j’appuie sur A, je répète nombreCotes fois : avancer, pause, tournerDroite, pause.
Dans MakeCode

Le vrai programme

Télécharger le programme (.hex)Code en texte (.ts)
Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let coteMs = 1000
let virageMs = 400
let nombreCotes = 4
function avancer() {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 80)
basic.pause(coteMs)
maqueen.motorStop(maqueen.Motors.All)
}
function tournerDroite() {
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 80)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CCW, 80)
basic.pause(virageMs)
maqueen.motorStop(maqueen.Motors.All)
}
input.onButtonPressed(Button.A, function () {
for (let index = 0; index < nombreCotes; index++) {
avancer()
basic.pause(200)
tournerDroite()
basic.pause(200)
}
})
③ Essayer

Testez pas à pas

  1. Comparez avec le carré de l’activité 5 : même résultat ?
  2. Changez seulement coteMs : que varie-t-il ?
  3. Pour un hexagone, étalonnez d’abord un pivot de 60°.
Ce que vous devez observer : Le robot fait le même carré, mais on règle la taille en changeant un seul nombre.

Si ça ne marche pas

  • Le robot ne fait pas un hexagone. Changer nombreCotes ne recalcule pas le virage : il faut régler virageMs.

Autres solutions : page Aide. Les programmes n’ont pas été essayés sur un robot réel ici : vos observations peuvent différer légèrement. Roues levées pour les premiers essais, puis sol dégagé.

④ Expliquer

Modifiez une chose, prévoyez, vérifiez

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Créez une fonction « tournerGauche ».
  • Faites un hexagone avec virageMs réétalonné.
