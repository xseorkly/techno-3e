Activité 15 sur 20 · Étape 3 : Fiabiliser et organiser

Suivre la ligne en évitant les chocs

Que faire quand deux informations demandent deux actions différentes ?

⏱ 30 minDifficulté ●●●
Votre mission

Le robot suit la ligne mais s’arrête dès qu’un obstacle apparaît à 20 cm : l’obstacle est prioritaire.

Matériel : Maqueen avec ultrason et capteurs de ligne, piste noire, carton

À la fin, je saurai :

  • Je sais donner une priorité entre deux règles.
  • Je sais tester un conflit entre deux capteurs.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Si le capteur de ligne dit « avance » et l’ultrason dit « stop », qui a raison ?
  2. Le robot repart-il après l’arrêt ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Toujours :
   je mesure la distance ;
   si invalide ou ≤ 20 cm : j’arrête ;
   sinon : je suis la ligne (table de l’activité 10) ;
   j’attends 20 ms.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
toujoursContrôle

Ce que fait ce bloc : Répète sans fin.

Pourquoi il est là : Deux capteurs à surveiller.

3
définir distance ▾ à Lire la distance du capteur à ultrasons (en cm)Mémoire

Ce que fait ce bloc : Mesure la distance.

Pourquoi il est là : Première information : y a-t-il un obstacle ?

4
si distance invalide ou ≤ 20 alorsContrôle

Ce que fait ce bloc : Obstacle ou mesure douteuse.

Pourquoi il est là : On teste la sécurité en premier.

5
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Sécurité d’abord : arrêt.

6
sinonContrôle

Ce que fait ce bloc : Pas d’obstacle.

Pourquoi il est là : On peut alors suivre la ligne.

7
(table de suivi de ligne de l’activité 10)Contrôle

Ce que fait ce bloc : Lit les deux capteurs puis applique les 4 règles.

Pourquoi il est là : On réutilise exactement le programme précédent.

8
pause (ms) 20Contrôle

Ce que fait ce bloc : Le programme attend 20 millisecondes (soit 0.02 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Cadence.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let gauche = 0
let droite = 0
let distance = 0
basic.forever(function () {
distance = maqueen.Ultrasonic()
if (distance <= 0 || distance >= 500 || distance <= 20) {
maqueen.motorStop(maqueen.Motors.All)
} else {
gauche = maqueen.readPatrol(maqueen.Patrol.PatrolLeft)
droite = maqueen.readPatrol(maqueen.Patrol.PatrolRight)
if (gauche == 0 && droite == 0) {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 60)
} else if (gauche == 0 && droite == 1) {
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 0)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CW, 60)
} else if (gauche == 1 && droite == 0) {
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 60)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CW, 0)
} else {
maqueen.motorStop(maqueen.Motors.All)
}
}
basic.pause(20)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Testez séparément le suivi de ligne et la distance.
  2. 2
    Présentez un obstacle alors que les deux capteurs voient du noir.
  3. 3
    Retirez l’obstacle : le robot repart-il ?
Ce que vous devez observer : L’obstacle gagne : le robot s’arrête. Il repart quand la mesure est valide et la ligne visible.
Si ça ne marche pas
  • Le robot ne repart pas. Sans écho valide, il reste arrêté : placez une cible plane ou ajustez la politique.

Autres solutions : page Besoin d’aide ?

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Inversez l’ordre des deux tests : qu’arrive-t-il ?
