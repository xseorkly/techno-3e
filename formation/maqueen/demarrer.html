Formation professeurs stagiaires · Maqueen · Étape 1

Démarrer avec MakeCode

De la boîte au premier message sur le micro:bit. Comptez 20 minutes.

← SommaireBesoin d’aide ?
Ce qu’il vous faut

Matériel et logiciel

  • Un Maqueen classique avec 3 piles AAA et une carte micro:bit.
  • Un câble USB qui transfère des données (pas seulement la charge).
  • Un ordinateur avec un navigateur récent. Aucun compte n’est nécessaire.
  • Un sol plat, dégagé, loin du bord d’une table.
Les 7 étapes

Du déballage au premier message

  1. Mettez les piles.

    Trois piles AAA dans le compartiment sous le robot. Le câble USB seul ne suffit pas pour les moteurs.

  2. Ouvrez MakeCode.

    Dans le navigateur : makecode.microbit.org. Cliquez sur « Importer ».

  3. Importez le fichier .hex.

    Téléchargez le fichier de l’activité 1, puis « Importer un fichier » dans MakeCode. Le projet s’ouvre avec ses blocs.

  4. Ajoutez l’extension Maqueen (si MakeCode la demande).

    Dans « Extensions », saisissez https://github.com/DFRobot/pxt-maqueen et choisissez « maqueen ». Utilisez la catégorie Maqueen v4 pour le Maqueen classique, pas Maqueen v5 ni Plus.

  5. Branchez la carte micro:bit à l’ordinateur.

    Un disque nommé MICROBIT apparaît.

  6. Copiez le fichier .hex sur ce disque.

    Attendez la fin du clignotement orange. Le fichier disparaît ensuite : c’est normal.

  7. Placez la carte dans le robot et allumez-le.

    Coupez l’alimentation pendant l’insertion. Vous devez lire PRET sur la matrice de LED.

Point de contrôle. Si vous voyez PRET puis une coche en appuyant sur A, le transfert fonctionne : passez à l’activité 1. Sinon : Aide.
Un piège à connaître

En français, « arrière » fait avancer le robot

Dans la version française de l’extension Maqueen, les libellés des directions sont inversés : « arrière » correspond au sens qui fait avancer le robot (code officiel « CW ») et « avant » au sens qui le fait reculer (« CCW »). Ce sont les mots qui divergent, pas les programmes fournis.

  • Importez toujours le fichier .hex fourni plutôt que de reconstruire le programme avec les mots avant/arrière.
  • Vérifiez le sens des roues levées avant tout essai au sol.
  • Dans ce dossier, un bandeau « ⚠ fait AVANCER » ou « ⚠ fait RECULER » rappelle l’effet réel.
Sécurité de départ

Trois habitudes

  • Roues levées pour le premier essai de chaque programme.
  • Zone dégagée, loin du bord d’une table ; prévoir un bouton B d’arrêt dès que le robot roule seul.
  • Gardez la main près de l’interrupteur.
