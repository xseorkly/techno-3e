Parcourir un carré

Quelle partie du trajet faut-il répéter pour dessiner un carré ?

⏱ 20 minDifficulté ●●●
Votre mission

Le robot avance, tourne, avance, tourne… quatre fois, pour revenir près de son point de départ.

Matériel : Maqueen monté, sol dégagé (1,5 m × 1,5 m), ruban

À la fin, je saurai :

  • Je sais répéter une séquence avec une boucle.
  • Je comprends pourquoi le résultat n’est jamais un carré parfait.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Quelles actions se répètent 4 fois ?
  2. Le robot reviendra-t-il exactement au même endroit ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Quand j’appuie sur A, je répète 4 fois :
   1. j’avance 1000 ms puis j’arrête, j’attends 200 ms ;
   2. je pivote 400 ms vers la droite puis j’arrête, j’attends 200 ms.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

3
répéter 4 foisContrôle

Ce que fait ce bloc : Répète quatre fois tous les blocs placés à l’intérieur.

Pourquoi il est là : Un carré a quatre côtés identiques : on écrit la séquence une fois et on la répète.

Mot à connaître. Une « boucle » répète des instructions. Ici le nombre de répétitions est 4.

4
Moteur Tous ▾ dir arrière ▾ vitesse 80 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : Fait tourner les deux roues dans le même sens, à la puissance 80. Le robot roule tout droit.

Pourquoi il est là : Premier élément de la séquence : un côté du carré.

Dans ce bloc, il y a :

  • Tous ▾Les deux moteurs à la fois (M1 = gauche, M2 = droite).
  • dir arrière ⚠ fait AVANCERLe sens de rotation. Piège : dans la version française de MakeCode, « arrière » est en réalité le sens qui fait AVANCER le robot (erreur de traduction connue). Les programmes fournis sont corrects.
  • 80La puissance, de 0 à 255. Ce n’est pas une vitesse en cm/s.

À savoir. Le moteur continue de tourner tant qu’aucun autre ordre n’arrive (pause, stop…).

5
pause (ms) 1000Contrôle

Ce que fait ce bloc : Le programme attend 1000 millisecondes (soit 1 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Durée de l’avance.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

6
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : On s’arrête avant de tourner.

7
pause (ms) 200Contrôle

Ce que fait ce bloc : Le programme attend 200 millisecondes (soit 0.2 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Petite pause pour que le robot soit bien arrêté.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

8
Moteur M1 ▾ dir arrière ▾ vitesse 80 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : La roue gauche (M1) tourne dans le sens qui fait avancer, à la puissance 80.

Pourquoi il est là : Le virage commence.

9
Moteur M2 ▾ dir avant ▾ vitesse 80 ⚠ fait RECULERMoteurs

Ce que fait ce bloc : La roue droite (M2) tourne dans le sens contraire (elle recule), à la puissance 80.

Pourquoi il est là : Une roue qui avance et l’autre qui recule : le robot tourne sur place vers la droite, comme un char.

10
pause (ms) 400Contrôle

Ce que fait ce bloc : Le programme attend 400 millisecondes (soit 0.4 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Durée du quart de tour.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

11
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Fin du virage.

12
pause (ms) 200Contrôle

Ce que fait ce bloc : Le programme attend 200 millisecondes (soit 0.2 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Petite pause avant le côté suivant.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
input.onButtonPressed(Button.A, function () {
for (let index = 0; index < 4; index++) {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 80)
basic.pause(1000)
maqueen.motorStop(maqueen.Motors.All)
basic.pause(200)
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 80)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CCW, 80)
basic.pause(400)
maqueen.motorStop(maqueen.Motors.All)
basic.pause(200)
}
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Marquez au sol le point de départ.
  2. 2
    Appuyez sur A et laissez le robot finir.
  3. 3
    Marquez le point d’arrivée.
  4. 4
    Mesurez l’écart entre départ et arrivée.
Ce que vous devez observer : Le robot revient près du départ, avec un écart de quelques centimètres : chaque virage ajoute une petite erreur.
Si ça ne marche pas
  • Le robot fait une spirale. L’angle est trop grand ou trop petit : ajustez la durée du pivot (voir activité 11).
  • Il ne se ferme pas du tout. Vérifiez le nombre de répétitions (4) et les deux durées.

Autres solutions : page Besoin d’aide ?

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Passez à 3 répétitions sans changer le reste : que dessine-t-il ?
  • Raccourcissez la durée d’avance à 500 ms.
