Activité 17 sur 20 · Étape 4 : Piloter à distance

Fabriquer une télécommande radio

Comment un deuxième micro:bit peut-il piloter le robot à distance ?

← FormationAccueilPlanActivitésLe robotEnseignerLimites & IAAide
En une phrase

Une première carte micro:bit sert de télécommande (boutons A et B) et envoie des ordres par radio à celle du robot. Si la télécommande se tait ou est lâchée, le robot s’arrête.

Durée estimée
40 min
Difficulté
●●●
Matériel
2 cartes micro:bit (une dans le robot, une télécommande), 2 câbles USB
Lancement
La télécommande envoie en continu ; le robot obéit

À la fin, je saurai :

  • Je sais faire communiquer deux micro:bit.
  • Je comprends ce qu’est un « protocole » : une règle commune de messages.
  • Je sais prévoir un arrêt de sécurité.
① Prédire

Avant de regarder le programme

Répondez par écrit (une phrase suffit). Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Que doivent avoir en commun l’émetteur et le récepteur pour se comprendre ?
  2. Que doit faire le robot si la télécommande tombe en panne ?
② Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme est un empilement de blocs, à lire de haut en bas. La couleur d’un bloc indique son rôle. Chaque bloc est expliqué dans l’ordre.

DépartContrôleMoteursCapteurAffichage / LEDMémoireCalculMa fonctionCommunication

Les blocs ci-dessous sont redessinés pour être lisibles ; la vraie capture de MakeCode est plus bas. Les libellés peuvent différer légèrement selon la version de MakeCode.

Programme 1 — La télécommande (micro:bit n°1, à la main)

1
radio définir groupe 1Communication

Ce que fait ce bloc : Choisit le « canal » de la radio : seuls les micro:bit réglés sur le même numéro s’entendent.

Pourquoi il est là : C’est comme une fréquence de talkie-walkie : l’émetteur et le robot doivent avoir le même numéro.

Mot à connaître. Un « groupe radio » est un numéro de canal (de 0 à 255).

2
toujoursContrôle

Ce que fait ce bloc : Répète sans fin.

Pourquoi il est là : Pour envoyer un ordre régulièrement, tant qu’on appuie.

3
si bouton A pressé et bouton B pressé alorsContrôle

Ce que fait ce bloc : Les deux boutons sont enfoncés ensemble.

Pourquoi il est là : Ce choix signifie « avancer ».

4
radio envoyer chaîne FCommunication

Ce que fait ce bloc : Envoie la lettre F (Forward = avancer) à tous les micro:bit du groupe.

Pourquoi il est là : Le message est très court : une lettre suffit pour un protocole simple.

Mot à connaître. Un « protocole » est la règle qui dit quel message veut dire quelle action : F = avancer, L = gauche, R = droite, S = stop.

5
sinon si A seul → envoyer « L » ; sinon si B seul → envoyer « R »Contrôle

Ce que fait ce bloc : A seul : « L » (gauche). B seul : « R » (droite).

Pourquoi il est là : Chaque bouton a une signification.

6
sinon → envoyer « S »Contrôle

Ce que fait ce bloc : Aucun bouton : « S » (stop).

Pourquoi il est là : Sécurité : quand on lâche, le robot reçoit l’ordre de s’arrêter.

7
pause (ms) 100Contrôle

Ce que fait ce bloc : Le programme attend 100 millisecondes (soit 0.1 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : On envoie un message environ 10 fois par seconde.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Programme 2 — Le robot (micro:bit n°2, dans le Maqueen)

8
radio définir groupe 1Communication

Ce que fait ce bloc : Même canal que la télécommande.

Pourquoi il est là : Si les numéros sont différents, rien ne passe.

9
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

10
quand radio reçoit receivedStringCommunication

Ce que fait ce bloc : S’exécute à chaque message reçu. La lettre reçue est rangée dans « receivedString ».

Pourquoi il est là : Le robot n’a pas besoin de demander : il réagit dès qu’un message arrive.

Mot à connaître. C’est un événement : « un message radio est arrivé ».

11
définir dernier ▾ à temps d’exécutionMémoire

Ce que fait ce bloc : Note l’heure du dernier message reçu.

Pourquoi il est là : Sert à détecter une télécommande silencieuse.

12
si receivedString = « F » → avancer ; « L » → pivot gauche ; « R » → pivot droite ; sinon → stopContrôle

Ce que fait ce bloc : Convertit chaque lettre en action sur les moteurs.

Pourquoi il est là : C’est ici que le protocole prend son sens : lettre → mouvement.

13
toujoursContrôle

Ce que fait ce bloc : Surveille en permanence.

Pourquoi il est là : Il faut une boucle indépendante pour la sécurité.

14
si temps d’exécution − dernier > 500 alorsContrôle

Ce que fait ce bloc : Plus aucun message depuis plus d’une demi-seconde.

Pourquoi il est là : Télécommande éteinte, hors de portée ou batterie vide.

15
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Arrêt de sécurité : le robot ne continue jamais « à l’aveugle ».

Le programme en français

Le même programme, avec des phrases

Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Télécommande : groupe radio 1 ; toutes les 100 ms :
   A+B → envoyer « F » ; A → « L » ; B → « R » ; rien → « S ».
Robot : groupe radio 1 ; à chaque message reçu :
   je note l’heure et j’exécute l’ordre (F, L, R ou stop).
   Toujours : si aucun message depuis 500 ms, j’arrête.

③ Essayer

Testez pas à pas

  1. Transférez le programme « télécommande » sur la carte n°1 et le programme « robot » sur la carte n°2.
  2. Robot roues levées : testez A+B, A, B, puis rien.
  3. Posez le robot au sol dans un espace dégagé et pilotez-le.
  4. Éteignez la télécommande en marche : le robot doit s’arrêter en moins d’une seconde.
Ce que vous devez observer : Le robot suit les ordres tant qu’on appuie, et s’arrête dès qu’on lâche ou qu’on éteint la télécommande.

Si ça ne marche pas

  • Le robot ne réagit pas. Même numéro de groupe radio des deux côtés ? Les deux programmes sont-ils sur les bonnes cartes ?
  • Il tourne dans le mauvais sens. Inversez L et R dans le programme du robot.
  • Plusieurs groupes de stagiaires se perturbent. Donnez un numéro de groupe radio différent à chaque binôme.

Autres solutions : page Aide. Les programmes n’ont pas été essayés sur un robot réel ici : vos observations peuvent différer légèrement. Roues levées pour les premiers essais, puis sol dégagé.

④ Expliquer

Modifiez une chose, prévoyez, vérifiez

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Changez le numéro de groupe : le robot obéit-il encore ?
  • Ajoutez une lettre « T » pour allumer les phares.
⑤ Transposer

Et dans ma classe ?

Ce que l’élève apprend
Comprendre la communication entre deux objets (émetteur, récepteur, protocole).
Ce que je donne
Le programme du robot ; les élèves écrivent la télécommande, ou l’inverse.
Piège à anticiper
Dix groupes sur le même numéro de radio : les robots s’obéissent entre eux. Prévoyez un numéro par binôme.
Trace écrite attendue
Un tableau « lettre → action » écrit par les élèves.
