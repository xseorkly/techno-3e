Suivre une ligne

Quelle action associer à chacune des quatre situations des capteurs ?

⏱ 30 minDifficulté ●●●
Votre mission

Le robot suit une ligne noire : il avance si les deux capteurs voient le noir, corrige à gauche ou à droite sinon, et s’arrête s’il a perdu la ligne.

Matériel : Maqueen, piste noire assez large (ruban de 2 cm minimum) à courbes larges

À la fin, je saurai :

  • Je sais traduire une table de décision en conditions.
  • Je comprends que le robot réagit seulement aux 4 cas prévus.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Si seul le capteur gauche voit le noir, de quel côté faut-il corriger ?
  2. Que doit faire le robot s’il ne voit plus de noir ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Toujours, toutes les 20 ms :
   je lis les deux capteurs ;
   noir/noir : j’avance à 60 ;
   noir à gauche seulement : je ralentis la roue gauche à 0 (virage à gauche) ;
   noir à droite seulement : je ralentis la roue droite à 0 (virage à droite) ;
   blanc/blanc : j’arrête.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
toujoursContrôle

Ce que fait ce bloc : Répète sans fin les blocs qu’il contient.

Pourquoi il est là : Le robot doit relire la piste en permanence.

3
définir gauche ▾ à Lire détecteur DétecteurGauche ▾Mémoire

Ce que fait ce bloc : Lit le capteur gauche.

Pourquoi il est là : Information de départ.

4
définir droite ▾ à Lire détecteur DétecteurDroite ▾Mémoire

Ce que fait ce bloc : Lit le capteur droit.

Pourquoi il est là : Seconde information.

5
si gauche = 0 et droite = 0 alorsContrôle

Ce que fait ce bloc : Les deux capteurs voient le noir : on est bien centré.

Pourquoi il est là : C’est le cas normal : tout droit.

6
Moteur Tous ▾ dir arrière ▾ vitesse 60 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : Fait tourner les deux roues dans le même sens, à la puissance 60. Le robot roule tout droit.

Pourquoi il est là : Pas de correction à faire.

Dans ce bloc, il y a :

  • Tous ▾Les deux moteurs à la fois (M1 = gauche, M2 = droite).
  • dir arrière ⚠ fait AVANCERLe sens de rotation. Piège : dans la version française de MakeCode, « arrière » est en réalité le sens qui fait AVANCER le robot (erreur de traduction connue). Les programmes fournis sont corrects.
  • 60La puissance, de 0 à 255. Ce n’est pas une vitesse en cm/s.

À savoir. Le moteur continue de tourner tant qu’aucun autre ordre n’arrive (pause, stop…).

7
sinon si gauche = 0 et droite = 1 alorsContrôle

Ce que fait ce bloc : Seul le capteur gauche voit encore le noir : la ligne part vers la gauche.

Pourquoi il est là : Il faut tourner vers la gauche.

8
Moteur M1 ▾ vitesse 0 · Moteur M2 ▾ vitesse 60Moteurs

Ce que fait ce bloc : La roue gauche s’arrête, la roue droite continue : le robot tourne vers la gauche.

Pourquoi il est là : Corriger consiste à ralentir la roue du côté où on veut tourner.

9
sinon si gauche = 1 et droite = 0 alorsContrôle

Ce que fait ce bloc : Seul le capteur droit voit le noir : la ligne part vers la droite.

Pourquoi il est là : Il faut tourner vers la droite.

10
Moteur M1 ▾ vitesse 60 · Moteur M2 ▾ vitesse 0Moteurs

Ce que fait ce bloc : La roue droite s’arrête, la gauche continue : le robot tourne vers la droite.

Pourquoi il est là : Même principe en miroir.

11
sinonContrôle

Ce que fait ce bloc : Blanc/blanc : la ligne est perdue.

Pourquoi il est là : On ne sait plus où aller : le plus prudent est de s’arrêter.

12
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Arrêt de sécurité.

13
pause (ms) 20Contrôle

Ce que fait ce bloc : Le programme attend 20 millisecondes (soit 0.02 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Rafraîchit la mesure 50 fois par seconde environ.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let gauche = 0
let droite = 0
basic.forever(function () {
gauche = maqueen.readPatrol(maqueen.Patrol.PatrolLeft)
droite = maqueen.readPatrol(maqueen.Patrol.PatrolRight)
if (gauche == 0 && droite == 0) {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 60)
} else if (gauche == 0 && droite == 1) {
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 0)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CW, 60)
} else if (gauche == 1 && droite == 0) {
maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 60)
maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CW, 0)
} else {
maqueen.motorStop(maqueen.Motors.All)
}
basic.pause(20)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Faites la piste avec du ruban noir large sur fond clair.
  2. 2
    Vérifiez à la main les 4 situations, roues levées.
  3. 3
    Posez le robot sur la piste avant de l’allumer.
  4. 4
    Faites suivre un tracé à courbes larges ; notez où il perd la ligne.
Ce que vous devez observer : Le robot suit la piste en corrigeant, parfois par à-coups. Il s’arrête quand il perd la ligne ou dans un virage trop serré.
Si ça ne marche pas
  • Il tourne dans le mauvais sens. Inversez les deux commandes de correction.
  • Il s’arrête tout de suite. La ligne est trop étroite : elle passe entre les deux capteurs (vue blanc/blanc).

Autres solutions : page Besoin d’aide ?

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Comparez les vitesses 40 et 60 sur le même tracé.
  • Remplacez le 0 de correction par 20 : le suivi est-il plus fluide ?
