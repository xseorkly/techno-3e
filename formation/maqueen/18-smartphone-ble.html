Piloter avec un smartphone

Comment un téléphone peut-il envoyer des ordres au robot ?

⏱ 60 minDifficulté ●●●
Votre mission

Le smartphone affiche des boutons (avancer, reculer, gauche, droite, stop). Chaque bouton envoie une lettre par Bluetooth au micro:bit, qui commande les moteurs.

Matériel : Maqueen avec micro:bit V2 (conseillé), smartphone Android ou iOS avec Bluetooth, compte MIT App Inventor

À la fin, je saurai :

  • Je comprends la chaîne smartphone → Bluetooth → micro:bit → moteurs.
  • Je sais recevoir des ordres par Bluetooth dans MakeCode.

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Au démarrage : je démarre le service Bluetooth, j’arrête les moteurs.
Si le téléphone se déconnecte : j’arrête les moteurs.
Quand une ligne arrive par Bluetooth : je lis la lettre ; F = avancer, B = reculer, L = gauche, R = droite, autre = stop.
La partie smartphone

L’application, étape par étape

L’application se fabrique dans MIT App Inventor, un outil en ligne qui fonctionne aussi avec des blocs. Voici les grandes étapes ; le détail technique complet est dans le tutoriel technique.

  1. Dessiner l’écran.

    5 boutons : Avancer, Reculer, Gauche, Droite, Stop (le plus visible), et un bouton « Se connecter ».

  2. Ajouter l’extension Bluetooth.

    Importez l’extension « BluetoothLE » (version récente, surtout pour Android 12 ou plus).

  3. Se connecter au micro:bit.

    Un scan repère le micro:bit ; on s’y connecte avant d’autoriser les boutons.

  4. Envoyer un ordre.

    Chaque bouton envoie une lettre suivie d’un retour à la ligne : F, B, L, R ou S.

  5. Tester dans cet ordre :

    Stop d’abord, puis Avancer, puis les autres. Roues levées au début.

Sécurité. Prévoyez toujours un bouton STOP bien visible. Le robot doit aussi s’arrêter si la connexion est perdue (c’est le rôle du bloc « Bluetooth déconnecté »).

Programme du robot

1
démarrer le service UART BluetoothCommunication

Ce que fait ce bloc : Ouvre un « tuyau » Bluetooth permettant de recevoir de petits messages texte.

Pourquoi il est là : Sans lui, le smartphone ne peut pas envoyer d’ordres.

Mot à connaître. UART est une liaison série : on envoie des caractères l’un après l’autre.

2
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

3
quand Bluetooth est déconnectéCommunication

Ce que fait ce bloc : S’exécute quand le téléphone se déconnecte.

Pourquoi il est là : Sécurité : si le lien est coupé, le robot s’arrête.

4
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Le robot ne continue pas à rouler sans pilote.

5
quand des données UART sont reçues jusqu’à « nouvelle ligne »Communication

Ce que fait ce bloc : S’exécute chaque fois qu’une ligne de texte arrive.

Pourquoi il est là : Le téléphone termine chaque ordre par un retour à la ligne pour dire « message complet ».

6
définir commande ▾ à lire UART jusqu’à nouvelle ligneMémoire

Ce que fait ce bloc : Range dans « commande » la lettre reçue.

Pourquoi il est là : On garde l’ordre en mémoire pour le tester.

7
si commande = « F » → avancer ; « B » → reculer ; « L » → pivot gauche ; « R » → pivot droite ; sinon → stopContrôle

Ce que fait ce bloc : Convertit chaque lettre en action.

Pourquoi il est là : C’est le même protocole que l’activité 17.

Voir le code en texte (JavaScript)
// Micro:bit du robot Maqueen, piloté en Bluetooth (smartphone ou ordinateur)
// Extensions à ajouter dans MakeCode : maqueen (DFRobot/pxt-maqueen) ET Bluetooth.
// Attention : Bluetooth et Radio ne peuvent pas être utilisés dans le même projet.
// Avec une carte micro:bit V1, la mémoire peut être insuffisante : préférer la V2.
let commande = ""
bluetooth.startUartService()
maqueen.motorStop(maqueen.Motors.All)
bluetooth.onBluetoothDisconnected(function () {
    maqueen.motorStop(maqueen.Motors.All)
})
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    commande = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (commande == "F") {
        maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 60)
    } else if (commande == "B") {
        maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CCW, 60)
    } else if (commande == "L") {
        maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CCW, 50)
        maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CW, 50)
    } else if (commande == "R") {
        maqueen.motorRun(maqueen.Motors.M1, maqueen.Dir.CW, 50)
        maqueen.motorRun(maqueen.Motors.M2, maqueen.Dir.CCW, 50)
    } else {
        maqueen.motorStop(maqueen.Motors.All)
    }
})

Charger et essayer

Charger le programme

  1. 1
    Ouvrez makecode.microbit.org et créez un nouveau projet.
  2. 2
    Passez en JavaScript (bouton en haut) et collez le code de l’étape ② (ou téléchargez-le : Programme du robot (réception Bluetooth) ).
  3. 3
    Ajoutez les extensions indiquées en commentaire en tête du code, puis cliquez sur « Télécharger ».
  4. 4
    Posez le micro:bit sur le robot et allumez-le.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Ajoutez les extensions Maqueen et Bluetooth dans MakeCode (pas de Radio) et transférez le programme.
  2. 2
    Testez d’abord avec une application d’essai ou un outil de terminal Bluetooth, roues levées.
  3. 3
    Connectez l’application App Inventor et testez Stop, puis Avancer.
  4. 4
    Coupez le Bluetooth du téléphone : le robot doit s’arrêter.
Ce que vous devez observer : Chaque bouton du téléphone produit le mouvement correspondant, et le robot s’arrête à la déconnexion.
Si ça ne marche pas
  • Le micro:bit n’apparaît pas au scan. Bluetooth actif, service UART démarré, autorisations Android accordées, micro:bit pas déjà connecté ailleurs.
  • Message d’erreur de mémoire (020) avec micro:bit V1. Le Bluetooth demande beaucoup de mémoire : utilisez une carte micro:bit V2.
  • Gauche et droite inversées. Vérifiez les deux sens de rotation et le sens de L et R.
