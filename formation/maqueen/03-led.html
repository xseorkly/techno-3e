① Prédire

Avant de regarder le programme

Répondez par écrit (une phrase suffit). Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Quel phare va s’allumer en premier ?
  2. Les deux seront-ils allumés en même temps ?
② Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme est un empilement de blocs, à lire de haut en bas. La couleur d’un bloc indique son rôle. Chaque bloc est expliqué dans l’ordre.

DépartContrôleMoteursCapteurAffichage / LEDMémoireCalculMa fonctionCommunication

Les blocs ci-dessous sont redessinés pour être lisibles ; la vraie capture de MakeCode est plus bas. Les libellés peuvent différer légèrement selon la version de MakeCode.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

3
LEDlight LEDGauche ▾ turn allumer ▾Affichage / LED

Ce que fait ce bloc : Allume la LED avant gauche du robot (pas la matrice du micro:bit).

Pourquoi il est là : Ce bloc donne un signal lumineux sans faire bouger le robot : pratique pour tester sans risque.

4
pause (ms) 500Contrôle

Ce que fait ce bloc : Le programme attend 500 millisecondes (soit 0.5 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Les LED restent allumées pendant que le programme attend.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

5
LEDlight LEDGauche ▾ turn éteindre ▾Affichage / LED

Ce que fait ce bloc : Éteint la LED gauche.

Pourquoi il est là : Sans cela elle resterait allumée.

6
LEDlight LEDDroite ▾ turn allumer ▾Affichage / LED

Ce que fait ce bloc : Allume la LED avant droite.

Pourquoi il est là : Même principe, du côté droit.

7
pause (ms) 500Contrôle

Ce que fait ce bloc : Le programme attend 500 millisecondes (soit 0.5 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Même attente.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

8
LEDlight LEDDroite ▾ turn éteindre ▾Affichage / LED

Ce que fait ce bloc : Éteint la LED droite.

Pourquoi il est là : On remet le robot dans son état de départ.

Le programme en français

Le même programme, avec des phrases

Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Quand j’appuie sur A :
   1. j’allume la LED gauche, j’attends 0,5 s, je l’éteins ;
   2. j’allume la LED droite, j’attends 0,5 s, je l’éteins.

③ Essayer

Testez pas à pas

  1. Repérez les deux LED à l’avant du robot (elles ne sont pas sur le micro:bit).
  2. Appuyez sur A et notez l’ordre gauche puis droite.
  3. Vérifiez qu’à la fin les deux LED sont éteintes.
Ce que vous devez observer : Phare gauche, puis phare droit, chacun une demi-seconde. Le robot reste immobile.

Si ça ne marche pas

  • Aucune LED ne s’allume. Vérifiez que le robot est allumé (interrupteur) et que le micro:bit est bien enfoncé.
  • Les LED sont dans le mauvais ordre. Relisez le programme : l’ordre des blocs est l’ordre de l’action.

④ Expliquer

Modifiez une chose, prévoyez, vérifiez

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Inversez l’ordre des deux LED.
  • Faites clignoter la LED gauche 3 fois (indice : bloc « répéter »).
