Vérifier le premier transfert

Comment savoir que mon programme est bien arrivé dans le robot ?

⏱ 20 minDifficulté ●●●
Votre mission

Le micro:bit écrit « PRET » sur sa matrice de LED, puis une coche apparaît quand on appuie sur A. C’est le test qui prouve que le transfert fonctionne.

Matériel : Maqueen + micro:bit, câble USB de données

À la fin, je saurai :

  • Je sais envoyer un programme dans le micro:bit.
  • Je sais distinguer un problème de transfert d’un problème de robot.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Quand je mets le robot sous tension, que va-t-il afficher ?
  2. Que se passera-t-il si j’appuie sur A ? Et sur B ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Au démarrage :
   1. j’arrête les deux moteurs ;
   2. j’écris « PRET » sur la matrice de LED.
Quand j’appuie sur A :
   je dessine une coche.

Le programme

1
au démarrageDépart

Ce que fait ce bloc : Tout ce qui est rangé dans ce bloc s’exécute une seule fois, quand on met le robot sous tension (ou qu’on redémarre le micro:bit).

Pourquoi il est là : C’est la « mise en place » : on prépare le robot avant que l’utilisateur ne fasse quoi que ce soit.

Mot à connaître. Un « événement » est un moment qui déclenche des instructions : ici, le démarrage.

2
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

3
afficher texte PRETAffichage / LED

Ce que fait ce bloc : Fait défiler le mot PRET sur la matrice de 25 LED du micro:bit.

Pourquoi il est là : C’est le signe visible que le programme a démarré : c’est la preuve que le transfert a réussi.

4
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Bloc de départ : tout ce qui est dessous s’exécute quand on appuie sur le bouton A du micro:bit.

Pourquoi il est là : C’est vous qui décidez du moment où le robot agit. Sans cela il partirait dès l’allumage.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

5
montrer l’icône coche ▾Affichage / LED

Ce que fait ce bloc : Dessine une coche sur la matrice de LED.

Pourquoi il est là : Un deuxième signal, déclenché par vous : il montre que le bouton A est bien lu par le programme.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
basic.showString("PRET")
input.onButtonPressed(Button.A, function () {
basic.showIcon(IconNames.Yes)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Ouvrez MakeCode et importez le fichier .hex (voir « Démarrer »).
  2. 2
    Branchez le micro:bit à l’ordinateur et copiez le fichier sur le disque MICROBIT. Attendez la fin du clignotement orange.
  3. 3
    Placez le micro:bit dans le robot et allumez-le : observez « PRET ».
  4. 4
    Appuyez sur A : une coche doit apparaître.
Ce que vous devez observer : Le mot PRET défile, puis la coche s’affiche à l’appui sur A. Aucun déplacement : le robot ne bouge pas.
Si ça ne marche pas
  • Aucun disque MICROBIT n’apparaît. Le câble ne transfère probablement que le courant : essayez un autre câble USB.
  • Le mot ne s’affiche pas. Vérifiez que le fichier a bien été copié sur le disque MICROBIT et que le clignotement s’est arrêté.

Autres solutions : page Besoin d’aide ?

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Remplacez PRET par votre prénom : prévoyez ce que vous allez voir avant de transférer.
  • Ajoutez un deuxième affichage pour le bouton B.

Et dans ma classe ?

Ce que l’élève apprend
Faire comprendre qu’un programme est une suite d’instructions déclenchées par des événements.
Ce que je donne
Le programme complet ; les élèves repèrent les deux événements.
Piège à anticiper
Les élèves croient que le programme « s’exécute dans l’ordinateur » : montrez le transfert.
Trace écrite attendue
Une phrase « Quand …, le robot … ».
