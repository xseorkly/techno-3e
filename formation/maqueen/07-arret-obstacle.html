Activité 7 sur 20 · Étape 2 : Mesurer et décider

S’arrêter devant un obstacle

Comment transformer une mesure en décision répétée ?

⏱ 25 minDifficulté ●●●
Votre mission

Quand on appuie sur A, le robot avance. Dès que le capteur voit un obstacle à 20 cm ou moins (ou ne reçoit pas d’écho), il s’arrête.

Matériel : Maqueen avec ultrason, carton plat, sol dégagé

À la fin, je saurai :

  • Je sais écrire une condition « si … alors … sinon ».
  • Je sais utiliser une variable « actif / inactif ».
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. À quelle distance de l’obstacle le robot va-t-il s’arrêter ?
  2. Que se passe-t-il si j’enlève l’obstacle après l’arrêt ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Au démarrage : j’arrête les moteurs ; actif = faux.
Quand j’appuie sur A : actif = vrai.
Quand j’appuie sur B : actif = faux et j’arrête les moteurs.
Toujours, toutes les 50 ms, si actif :
   1. je mesure la distance ;
   2. si elle est invalide ou ≤ 20 cm : j’arrête et actif = faux ;
   3. sinon j’avance.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
définir actif ▾ à fauxMémoire

Ce que fait ce bloc : Crée une case mémoire « actif » qui vaut faux (le robot n’a pas le droit de rouler).

Pourquoi il est là : Elle sert d’interrupteur logiciel : le robot ne roule que si elle vaut vrai.

Mot à connaître. « Vrai / faux » sont les deux seules valeurs d’une condition.

3
lorsque le bouton A ▾ est presséDépart

Ce que fait ce bloc : Quand on appuie sur A, le robot reçoit l’autorisation de rouler.

Pourquoi il est là : C’est vous qui lancez la marche.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

4
définir actif ▾ à vraiMémoire

Ce que fait ce bloc : Met l’interrupteur sur « vrai ».

Pourquoi il est là : Le programme principal va maintenant faire avancer le robot.

5
lorsque le bouton B ▾ est presséDépart

Ce que fait ce bloc : Quand on appuie sur B, le robot s’arrête.

Pourquoi il est là : Bouton d’arrêt toujours disponible : indispensable pour un robot qui roule.

Mot à connaître. Les boutons A et B sont les deux boutons physiques de la carte micro:bit (sur la face avant, de part et d’autre de la matrice de LED).

6
définir actif ▾ à fauxMémoire

Ce que fait ce bloc : Retire l’autorisation de rouler.

Pourquoi il est là : Le robot ne repartira pas tout seul.

7
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Arrêt immédiat.

8
toujoursContrôle

Ce que fait ce bloc : Répète sans fin ce qui est dedans.

Pourquoi il est là : Le robot doit surveiller son capteur en permanence.

9
si actif alorsContrôle

Ce que fait ce bloc : N’exécute ce qui suit que si « actif » vaut vrai.

Pourquoi il est là : Tant que A n’a pas été pressé, le robot reste inerte.

10
définir distance ▾ à Lire la distance du capteur à ultrasons (en cm)Mémoire

Ce que fait ce bloc : Mesure la distance.

Pourquoi il est là : On décide toujours à partir d’une mesure récente.

11
si distance ≤ 0 ou distance ≥ 500 ou distance ≤ 20 alors … sinon …Contrôle

Ce que fait ce bloc : Si la mesure est invalide (0 ou 500) ou si l’obstacle est à 20 cm ou moins, on arrête ; sinon on avance.

Pourquoi il est là : Le seuil de 20 cm est une marge de sécurité. Une mesure invalide est traitée comme un danger.

Dans ce bloc, il y a :

  • distance ≤ 20« est plus petit ou égal à 20 » : la condition d’arrêt. 20 est le seuil.
  • distance ≤ 0 ou ≥ 500Valeurs de remplacement quand le capteur ne reçoit pas d’écho : on ne les croit pas.

Mot à connaître. Un « seuil » est la valeur limite qui fait changer de comportement.

12
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Obstacle trop proche : arrêt.

13
définir actif ▾ à fauxMémoire

Ce que fait ce bloc : Retire l’autorisation de rouler.

Pourquoi il est là : Le robot ne repart pas tant qu’on ne rappuie pas sur A.

14
Moteur Tous ▾ dir arrière ▾ vitesse 80 ⚠ fait AVANCERMoteurs

Ce que fait ce bloc : Fait tourner les deux roues dans le même sens, à la puissance 80. Le robot roule tout droit.

Pourquoi il est là : Pas d’obstacle : le robot avance.

Dans ce bloc, il y a :

  • Tous ▾Les deux moteurs à la fois (M1 = gauche, M2 = droite).
  • dir arrière ⚠ fait AVANCERLe sens de rotation. Piège : dans la version française de MakeCode, « arrière » est en réalité le sens qui fait AVANCER le robot (erreur de traduction connue). Les programmes fournis sont corrects.
  • 80La puissance, de 0 à 255. Ce n’est pas une vitesse en cm/s.

À savoir. Le moteur continue de tourner tant qu’aucun autre ordre n’arrive (pause, stop…).

15
pause (ms) 50Contrôle

Ce que fait ce bloc : Le programme attend 50 millisecondes (soit 0.05 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Petite pause entre deux tours de boucle.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let actif = false
let distance = 0
input.onButtonPressed(Button.A, function () {
actif = true
})
input.onButtonPressed(Button.B, function () {
actif = false
maqueen.motorStop(maqueen.Motors.All)
})
basic.forever(function () {
if (actif) {
distance = maqueen.Ultrasonic()
if (distance <= 0 || distance >= 500 || distance <= 20) {
maqueen.motorStop(maqueen.Motors.All)
actif = false
} else {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 80)
}
}
basic.pause(50)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Placez le robot à 50 cm d’un carton plat, face à lui.
  2. 2
    Appuyez sur A et regardez où il s’arrête. Mesurez la distance.
  3. 3
    Appuyez sur B pendant une avance : il doit s’arrêter.
  4. 4
    Retirez le carton avant de lancer : que fait le robot ?
Ce que vous devez observer : Le robot s’arrête devant l’obstacle, à un peu moins de 20 cm (il roule encore un peu). Il ne repart pas seul.

Avant l’essai, roues levées : vérifiez que « avancer » fait bien tourner les roues vers l’avant. Dans MakeCode en français avec l’extension DFRobot pxt-maqueen, « arrière » peut correspondre au sens qui fait avancer le robot : si le sens est inversé sur votre robot, inversez-le dans le programme. Distance d’arrêt : 20 cm est le seuil de détection du capteur, pas la distance finale : le robot roule encore un instant. Mesurez la distance finale à la règle.

Si ça ne marche pas
  • Il ne s’arrête pas. Vérifiez le capteur et la nature de l’obstacle (plat, solide).
  • Il s’arrête loin. Mesure invalide : un obstacle mou ou de biais n’a pas d’écho exploitable.

4

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Comparez les seuils 15 cm et 25 cm.
  • Remplacez la vitesse 80 par 120 : l’arrêt se fait-il au même endroit ?
