Lire les deux capteurs de ligne

Que savent réellement les deux capteurs sous le robot ?

← FormationAccueilPlanActivitésLe robotEnseignerLimites & IAAide
En une phrase

Le robot affiche un code qui dit si chacun des deux capteurs sous lui voit du noir ou du blanc.

Durée estimée
25 min
Difficulté
●●●
Matériel
Maqueen avec capteurs de ligne (sous l’avant), feuille blanche, ruban noir
Lancement
Automatique (boucle « toujours »)

À la fin, je saurai :

  • Je sais lire les capteurs de ligne.
  • Je sais construire une table de vérité avec 4 cas.
① Prédire

Avant de regarder le programme

Répondez par écrit (une phrase suffit). Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Combien de situations différentes peut-on rencontrer avec deux capteurs ?
  2. Que lira-t-on sur une feuille blanche ?
② Le programme, bloc par bloc

Ce que fait chaque bloc

Un programme est un empilement de blocs, à lire de haut en bas. La couleur d’un bloc indique son rôle. Chaque bloc est expliqué dans l’ordre.

DépartContrôleMoteursCapteurAffichage / LEDMémoireCalculMa fonctionCommunication

Les blocs ci-dessous sont redessinés pour être lisibles ; la vraie capture de MakeCode est plus bas. Les libellés peuvent différer légèrement selon la version de MakeCode.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
toujoursContrôle

Ce que fait ce bloc : Répète sans fin le bloc.

Pourquoi il est là : Pour suivre en direct ce que voient les capteurs.

3
définir gauche ▾ à Lire détecteur DétecteurGauche ▾Mémoire

Ce que fait ce bloc : Lit le capteur de ligne de gauche : il renvoie 0 ou 1.

Pourquoi il est là : Les capteurs ne mesurent pas une distance mais seulement « noir ou blanc ».

Mot à connaître. 0 signifie « noir » (ligne vue) et 1 signifie « blanc » (fond vu). Un 0 ne veut donc pas dire « capteur en panne ».

4
définir droite ▾ à Lire détecteur DétecteurDroite ▾Mémoire

Ce que fait ce bloc : Lit le capteur de droite.

Pourquoi il est là : Même principe, côté droit.

5
écrire valeur « gauche » = gauche sur le port sérieAffichage / LED

Ce que fait ce bloc : Envoie la valeur au port série (visible dans MakeCode, console).

Pourquoi il est là : Permet d’observer sans regarder l’écran du robot, pratique pour s’entraîner.

6
afficher nombre 2 × gauche + droiteAffichage / LED

Ce que fait ce bloc : Affiche un seul nombre qui code les deux capteurs : 2×gauche + droite.

Pourquoi il est là : Ce nombre vaut 0, 1, 2 ou 3 : une valeur par situation possible.

Dans ce bloc, il y a :

  • 2 × gauche + droiteGauche compte double. Exemple : gauche = 1 et droite = 0 → 2.
7
pause (ms) 200Contrôle

Ce que fait ce bloc : Le programme attend 200 millisecondes (soit 0.2 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Rend l’affichage lisible.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Le programme en français

Le même programme, avec des phrases

Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Toujours :
   1. je lis le capteur gauche et le capteur droit (0 = noir, 1 = blanc) ;
   2. j’envoie les deux valeurs au port série ;
   3. j’affiche 2×gauche + droite ;
   4. j’attends 200 ms.
Dans MakeCode

Le vrai programme

Télécharger le programme (.hex)Code en texte (.ts)
Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let gauche = 0
let droite = 0
basic.forever(function () {
gauche = maqueen.readPatrol(maqueen.Patrol.PatrolLeft)
droite = maqueen.readPatrol(maqueen.Patrol.PatrolRight)
serial.writeValue("gauche", gauche)
serial.writeValue("droite", droite)
basic.showNumber(2 * gauche + droite)
basic.pause(200)
})
③ Essayer

Testez pas à pas

  1. Maintenez le robot immobile sur fond blanc : lisez le code (3 attendu).
  2. Placez seulement le capteur gauche sur le noir : code 1 ; seulement le droit : code 2.
  3. Placez les deux sur le noir : code 0.
  4. Consignez les 4 cas dans un tableau.
Ce que vous devez observer : Quatre situations, quatre codes : 3 (blanc/blanc), 1 (gauche noir), 2 (droite noir), 0 (noir/noir).

Si ça ne marche pas

  • Le code ne change pas. Les capteurs sont sous l’avant du robot : approchez-les du sol (quelques millimètres).
  • Valeurs inattendues. Une surface brillante ou un noir peu contrasté perturbe les capteurs.

④ Expliquer

Modifiez une chose, prévoyez, vérifiez

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Donnez une combinaison à un collègue : peut-il prévoir le code ?
  • Trouvez la largeur de ruban minimale détectée par un seul capteur.
