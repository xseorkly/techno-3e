Éviter le tremblement près d’un seuil

Comment éviter que le robot hésite sans cesse entre « marche » et « arrêt » ?

⏱ 30 minDifficulté ●●●
Votre mission

Le robot s’arrête à 15 cm de l’obstacle mais ne repart qu’à 25 cm : entre les deux, il garde sa décision précédente.

Matériel : Maqueen avec ultrason, carton plat, roues levées pour les premiers tests

À la fin, je saurai :

  • Je sais mémoriser un état dans une variable.
  • Je comprends l’utilité d’une zone « tampon » entre deux seuils.
1

Prédire

Avant de regarder, répondez par écrit, en une phrase. Se tromper ici est utile : c’est ce qui fait apprendre.

  1. Que ferait un robot qui s’arrête à 20 cm et repart dès 20 cm ?
  2. Que doit-il faire à 20 cm quand il avance ? Et quand il recule ?
2

Lire le programme

Voici le programme en français. Les lignes décalées vers la droite sont à l’intérieur d’une répétition ou d’une condition.

Toujours :
   je mesure la distance ;
   si invalide ou ≤ 15 cm : marche = faux ;
   sinon si ≥ 25 cm : marche = vrai ;
   (entre 15 et 25 : je ne change rien) ;
   si marche : j’avance à 50, sinon j’arrête ;
   j’attends 50 ms.

Le programme

1
Stop le moteur Tous ▾Moteurs

Ce que fait ce bloc : Coupe les deux moteurs : les roues cessent de tourner.

Pourquoi il est là : Placé au démarrage, il garantit que le robot ne partira pas tout seul quand on l’allume. C’est une règle de sécurité à toujours mettre en premier.

2
toujoursContrôle

Ce que fait ce bloc : Répète sans fin.

Pourquoi il est là : Il faut relire le capteur en permanence.

3
définir distance ▾ à Lire la distance du capteur à ultrasons (en cm)Mémoire

Ce que fait ce bloc : Mesure la distance.

Pourquoi il est là : Base de toutes les décisions.

4
si distance ≤ 0 ou ≥ 500 alors marche = fauxContrôle

Ce que fait ce bloc : Mesure invalide : on s’arrête.

Pourquoi il est là : On ne roule jamais sur une mesure douteuse.

5
sinon si distance ≤ 15 alors marche = fauxContrôle

Ce que fait ce bloc : Obstacle proche : on arrête.

Pourquoi il est là : Premier seuil.

6
sinon si distance ≥ 25 alors marche = vraiContrôle

Ce que fait ce bloc : Obstacle loin : on repart.

Pourquoi il est là : Second seuil, plus éloigné que le premier.

7
(entre 15 et 25 cm : rien)Contrôle

Ce que fait ce bloc : Aucune ligne ne change « marche » : l’état précédent est conservé.

Pourquoi il est là : C’est la zone tampon, le cœur de l’hystérésis.

Mot à connaître. L’hystérésis est le fait qu’une décision dépende de l’état précédent et pas seulement de la mesure.

8
si marche alors avancer sinon stopContrôle

Ce que fait ce bloc : Commande les moteurs selon la mémoire « marche ».

Pourquoi il est là : On sépare la décision (marche vrai/faux) de l’action (moteurs).

9
pause (ms) 50Contrôle

Ce que fait ce bloc : Le programme attend 50 millisecondes (soit 0.05 seconde). Pendant ce temps, les moteurs gardent le dernier ordre reçu.

Pourquoi il est là : Cadence de mesure.

Mot à connaître. 1000 millisecondes (ms) = 1 seconde.

Voir le code en texte (JavaScript)
maqueen.motorStop(maqueen.Motors.All)
let marche = false
let distance = 0
basic.forever(function () {
distance = maqueen.Ultrasonic()
if (distance <= 0 || distance >= 500) {
marche = false
} else if (distance <= 15) {
marche = false
} else if (distance >= 25) {
marche = true
}
if (marche) {
maqueen.motorRun(maqueen.Motors.All, maqueen.Dir.CW, 50)
} else {
maqueen.motorStop(maqueen.Motors.All)
}
basic.pause(50)
})
3

Charger et essayer

Charger le programme

  1. 1
    Télécharger le programme
  2. 2
    Ouvrez makecode.microbit.org, cliquez sur « Importer », puis « Importer un fichier » et choisissez le fichier téléchargé.
  3. 3
    Branchez le micro:bit en USB, puis cliquez sur « Télécharger » dans MakeCode (ou copiez le fichier sur le disque MICROBIT). Attendez la fin du clignotement orange.
  4. 4
    Posez le micro:bit sur le robot et allumez-le. Premier transfert ? Voir Démarrer.

Essayer

Roues levées pour le premier essai, puis sol dégagé.

  1. 1
    Roues levées : approchez puis éloignez une cible.
  2. 2
    Vérifiez l’arrêt vers 15 cm et la reprise vers 25 cm.
  3. 3
    Placez la cible à 20 cm : le robot avance-t-il ? Cela dépend de l’histoire.
  4. 4
    Comparez avec la bande 18–22 cm.
Ce que vous devez observer : À 20 cm, le comportement diffère selon que le robot arrive de loin ou de près : c’est la mémoire.
Si ça ne marche pas
  • Le robot démarre tout seul. Le programme est automatique : tenez-le ou levez-le pour les premiers essais.
  • Il tremble quand même. Élargissez la zone entre les deux seuils.

Expliquer

Changez un seul élément, écrivez ce que vous pensez voir, puis vérifiez avec le robot. Si vous savez expliquer l’écart entre prévision et observation, vous avez compris.

  • Resserrez la bande à 18–22 cm.
  • Fixez les deux seuils dans des variables.
