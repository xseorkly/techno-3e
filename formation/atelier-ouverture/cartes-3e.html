Les 38 repères de progressivité de 3e

Les intitulés reprennent mot pour mot la colonne 3e des repères de progressivité du programme (BO n° 9 du 29 février 2024). Ils sont regroupés par thème, puis par compétence de fin de cycle : chaque thème porte trois des neuf compétences de fin de cycle, numérotées de C1 à C9. Le premier chiffre du code indique la compétence dans le thème (SFC2x = 2e compétence du thème SFC = C5). Ouvrez seulement le thème dont vous avez besoin ou affichez les trois pour préparer l’impression.

Cliquez sur une carte pour consulter les connaissances du programme à mobiliser. Une sélection contextualisée est proposée pour chaque repère de 3e ; les connaissances du BO concernent l’ensemble du cycle 4.
