Mission transmissionDémarche technologique

Comment transmettre les paquets par radio ?

Je vais faire communiquer deux cartes micro:bit et vérifier que tous les paquets arrivent.

5′Problème15′Analyser5′Retenir25′Réaliser5′Bilan
🎯 Ce que je vais apprendre

Objectif : Je vais faire communiquer deux cartes micro:bit et vérifier que tous les paquets arrivent.

Je réussis si : La station affiche 8 paquets reçus et j’explique le rôle du groupe radio.

5′

1. Le problème à résoudre

Toutes les équipes de la classe vont émettre en même temps.

Comment la station d’une équipe peut-elle ne recevoir que les paquets de son satellite ?

15′

2. Analyser : Lire les deux programmes

Voici les programmes fournis (MakeCode, mode JavaScript). Le premier va sur la carte « satellite », le second sur la carte « station ».

Programme

// Satellite simulé : envoie l'image 8 x 8 ligne par ligne (4e)
radio.setGroup(12)   // numéro de groupe propre à l'équipe (0 à 255)
let image = [
    "0000000001010101",
    "0000000101010101",
    "0000010101101001",
    "0001010110101001",
    "0101011010100101",
    "0101101010010100",
    "0101011001010000",
    "0101010101000000"
]
// Bouton A : envoyer les 8 lignes, une par paquet
input.onButtonPressed(Button.A, function () {
    for (let n = 0; n < 8; n++) {
        radio.sendString("" + n + ":" + image[n])   // paquet = numéro + ":" + 16 bits
        basic.showNumber(n)
        basic.pause(200)
    }
    basic.showIcon(IconNames.Yes)
})

// Station au sol : reçoit les lignes et repère les paquets manquants (4e)
radio.setGroup(12)   // même groupe que le satellite
let recues = ["", "", "", "", "", "", "", ""]

radio.onReceivedString(function (message) {
    if (message.charAt(1) == ":") {
        let n = parseInt(message.charAt(0))
        recues[n] = message.substr(2, 16)
        serial.writeLine(message)
    }
})

// Bouton B : bilan de réception
input.onButtonPressed(Button.B, function () {
    let manquants = 0
    for (let n = 0; n < 8; n++) {
        if (recues[n] == "") {
            manquants = manquants + 1
            serial.writeLine("Paquet manquant : " + n)
        }
    }
    basic.showNumber(8 - manquants)
})

Je réponds

5′

3. Je retiens

Trace écrite

Pour communiquer, deux terminaux doivent utiliser le même canal (ici, le même groupe radio) et le même format de message. Le groupe radio identifie les cartes d’une même équipe : sans lui, chaque station recevrait les paquets de toute la classe.

25′

4. Je réalise : Transmettre et vérifier

Transfère les programmes, choisis votre groupe radio, puis transmets l’image.

  1. Remplace 12 par le numéro de groupe de ton équipe dans les deux programmes.
  2. Transfère chaque programme sur sa carte.
  3. Appuie sur A sur le satellite, puis sur B sur la station.
  4. Ouvre la console série dans MakeCode pour lire les paquets reçus et redessine l’image.

Ce que je dois produire : Image reconstituée à partir des paquets reçus et capture de la console série.

Matériel : Deux cartes micro:bit, deux câbles USB, boîtier de piles, ordinateur avec MakeCode.

Besoin d’un coup de pouce ?

Si rien n’arrive : vérifie que les deux cartes ont le même groupe et que le satellite est alimenté.

5′

5. Je fais le bilan

Q1. Deux équipes utilisent le même groupe radio. Que se passe-t-il ?
Q2. Le message « 5:0101101010010100 » contient…

🤝 Mon travail en groupe

J’écoute, j’explique mes choix et j’accepte de changer d’avis quand les preuves l’exigent.

Correction (pour l’enseignant)

Objectif : Mettre en œuvre une communication entre deux terminaux ; résoudre un problème de communication.

Programme : Repère de 4e : « Résoudre des problèmes pour assurer la communication entre les différents terminaux dans un réseau informatique ».

Déroulé : Problème 5 min ; Analyser 15 min ; Retenir 5 min ; Réaliser 25 min ; Bilan 5 min.

Réponses de l’enquête

  1. À quoi sert radio.setGroup(12) ? À choisir un canal : seules les cartes du même groupe s’échangent des messages. Chaque équipe choisit un numéro différent.
  2. Que contient le message envoyé pour la ligne 3 ? 3:0001010110101001 — le numéro, deux-points, puis les 16 bits.
  3. Que fait la station quand on appuie sur B ? Elle compte les lignes vides, écrit les numéros manquants sur la liaison série et affiche le nombre de paquets reçus.

Production attendue

La station affiche 8 ; la console montre les paquets 0 à 7 ; l’image redessinée est identique à l’originale.

QCM

  1. Deux équipes utilisent le même groupe radio. Que se passe-t-il ? Réponse B : chaque station reçoit aussi les paquets de l’autre équipe. Le groupe radio sépare les équipes comme des canaux différents.
  2. Le message « 5:0101101010010100 » contient… Réponse B : le numéro de ligne 5 et 16 bits de données. Format du paquet : numéro, deux-points, 16 bits.

Point de vigilance : Distribuer les numéros de groupe au tableau avant la séance pour éviter les interférences entre équipes.
