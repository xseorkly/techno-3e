Trouver son chemin dans le réseau

Le vocabulaire, les commandes et les formules dont vous avez besoin pour relier le réseau du collège à Internet dans Filius, tracer le trajet d'une information et calculer un temps de transfert.

1

Avant de commencer

Le vocabulaire à connaître

Adresse IP

Numéro d'identification unique d'un appareil sur un réseau. En IPv4 : 4 séries de chiffres de 0 à 255, séparées par des points.

Passerelle

Adresse IP de l'équipement (souvent un routeur) par lequel un appareil doit passer pour sortir de son réseau local et joindre un autre réseau.

Table de routage

Structure de données d'un routeur qui indique, pour un réseau de destination donné, vers quel prochain routeur envoyer l'information. Comparable à un plan de ville.

Débit

Quantité de données transmises par seconde sur une liaison. S'exprime en bits par seconde : bps, kb/s, Mb/s, Gb/s, Tb/s.

2

Ligne de commande, dans Filius

Les commandes utiles

CommandeCe qu'elle donne
ipconfig Affiche la configuration réseau de la machine : son adresse IP, son masque, sa passerelle.
ping [adresse IP] Envoie 4 paquets vers l'adresse indiquée et affiche le temps de réponse de chacun (en ms), ou Timeout si l'appareil est injoignable.
traceroute [adresse IP] Affiche la liste des routeurs traversés (les « sauts ») pour atteindre l'adresse indiquée.
3

Manipulations

Dans Filius, comment...

  1. Ajouter une interface à un routeur — clic sur le routeur → onglet Général → bouton « Gérer les connexions » → ajouter une interface et lui donner une adresse IP.
  2. Configurer une adresse IP et une passerelle — double-clic sur l'appareil → renseigner adresse IP, masque et passerelle.
  3. Consulter ou compléter la table de routage — propriétés du routeur → onglet table de routage → cocher « routage automatique » si l'option existe, ou ajouter la ligne manquante (réseau de destination, prochain routeur).
  4. Simuler une panne — clic droit sur un câble → Supprimer. Pour rétablir la liaison, retracer le câble.
4

Calculer un temps de transfert

Trajet + débit = temps

Temps (s) = Taille (bits) ÷ Débit (bits/s)

Rappel : 1 octet = 8 bits. Une taille donnée en Mo doit être multipliée par 8 pour obtenir des Mb si le débit est exprimé en Mb/s.

5

Si ça bloque

En cas de blocage

Checklist de dépannage

  • ping répond « Timeout » → vérifier d'abord l'adresse IP et la passerelle de la machine avec ipconfig.
  • Impossible de joindre un autre réseau → vérifier la table de routage des routeurs traversés : la ligne vers le réseau de destination existe-t-elle ?
  • Après avoir modifié un câble ou une table de routage → attendre quelques secondes avant de retester, la mise à jour n'est pas immédiate.
  • Toujours bloqué → sauvegarder le fichier, comparer avec le schéma attendu, puis demander de l'aide.
