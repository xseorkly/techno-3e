RECETTE AUTOMATISÉE SUR VM HÉBERGÉES

GitHub Actions — Linux et Windows

Un workflow de recette a été ajouté au dépôt : il prévoit l'exécution réelle du pipeline Python, la génération d'une capture synthétique avec text2pcap, sa lecture avec TShark, l'analyse syntaxique des scripts PowerShell et une requête publique vers NVD. Il se déclenche sur les modifications des fichiers concernés ou manuellement.

Le fichier du workflow est publié, mais aucune exécution ni réussite sur VM n'a encore été confirmée. Active Directory, PingCastle, Wazuh et Greenbone nécessitent toujours leurs propres environnements de laboratoire. L'analyse syntaxique PowerShell ne remplace pas l'exécution des scripts dans un domaine AD.
Consulter ou lancer la recette GitHub Actions

Dans GitHub : Actions → Recette cybersécurité Horizon → Run workflow → main. Consulter ensuite les journaux des jobs Linux et Windows et les rapports téléchargeables. Aucun réseau d'établissement n'est visé.

Statut réel de la validation

Validation partielle, pas de recette VM. Les essais ont été effectués dans un conteneur Linux sans hyperviseur, sans Windows Server, sans Wazuh, sans Greenbone, sans Wireshark et sans PowerShell. L'accès réseau direct à GitHub était indisponible. Les fichiers testés ont été récupérés par le connecteur GitHub puis reconstitués localement ; leurs empreintes de blob Git SHA-1 ont été comparées à celles du dépôt et concordent. Les calculs Python et le navigateur Chromium ont été exécutés réellement ; le moteur Wazuh n'a pas été exécuté. Aucun réseau d'établissement n'a été testé.
