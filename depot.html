Déposer notre travail

Votre PDF part directement chez votre professeur. Aucun compte à créer, aucune connexion à faire. Un seul dépôt par groupe suffit : inscrivez tous les membres, le fichier comptera pour chacun.

1. Générez le PDF

Sur la fiche de l'activité, bouton « Générer le PDF ». Le fichier arrive dans les téléchargements.

2. Remplissez le formulaire

Les noms du groupe, l'activité concernée, et le code donné par le professeur.

3. Envoyez

Un message de confirmation s'affiche. Gardez le PDF : c'est votre trace de travail.

Qui dépose ?

Le premier élève est obligatoire. Ajoutez les autres membres du groupe s'il y en a, jusqu'à trois.

Si ça ne marche pas

« Code de dépôt incorrect » — le code est celui écrit au tableau, avec les majuscules.

« Seuls les fichiers PDF sont acceptés » — vous avez sans doute choisi une photo ou un document Word. Revenez sur la fiche et utilisez le bouton « Générer le PDF ».

Rien ne se passe — vérifiez la connexion, puis réessayez une fois. Si le problème persiste, gardez le PDF et prévenez le professeur : votre travail n'est pas perdu.

Chacun a rempli sa propre fiche ? Alors chacun dépose son PDF séparément, en n'inscrivant que son nom.
